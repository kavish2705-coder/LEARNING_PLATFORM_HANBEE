Control Flow Statements

Decision making and loops. Control the order in which statements run using if, switch, for, while and the jump statements.

01Decision Making

if, else if, else

int marks = 72;
if (marks >= 90) {
    System.out.println("A+");
} else if (marks >= 60) {
    System.out.println("B");
} else {
    System.out.println("Fail");
}
  • The condition must be a boolean (unlike C, if (x = 5) is a compile error for int)
  • Always use braces, even for one statement; it prevents bugs when adding lines later
  • Nested if is allowed, but flat else if chains read better

Ternary shortcut

String status = (age >= 18) ? "Adult" : "Minor";

switch statement (classic)

int day = 3;
switch (day) {
    case 1:
        System.out.println("Mon");
        break;
    case 2:
        System.out.println("Tue");
        break;
    default:
        System.out.println("Other");
}
  • Works with byte, short, char, int, wrappers, String and enum
  • Without break, execution falls through to the next case
  • default runs when no case matches (optional, may appear anywhere)

switch expression (Java 14+)

No fall-through and it returns a value.

String type = switch (day) {
    case 1, 7 -> "Weekend";
    case 2, 3, 4, 5, 6 -> "Weekday";
    default -> "Invalid";
};

Use yield inside a block when you need more than one statement.

int score = switch (grade) {
    case 'A' -> 90;
    case 'B' -> {
        System.out.println("Good");
        yield 75;
    }
    default -> 0;
};

Pattern matching in switch (Java 21)

static String describe(Object o) {
    return switch (o) {
        case Integer i when i > 100 -> "Big int " + i;
        case Integer i              -> "Int " + i;
        case String s               -> "String of length " + s.length();
        case null                   -> "null!";
        default                     -> "Something else";
    };
}

02Loops

for loop

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Three parts: initialisation, condition, update. Any part can be empty; for (;;) is an infinite loop.

while loop

Checks the condition before each iteration.

int n = 5;
while (n > 0) {
    System.out.println(n--);
}

do-while loop

Runs the body at least once, then checks the condition.

int choice;
do {
    choice = readChoice();
} while (choice != 0);

Enhanced for (for-each)

int[] marks = {70, 80, 90};
for (int m : marks) {
    System.out.println(m);
}
  • Works on arrays and anything that implements Iterable
  • You cannot get the index, and you cannot safely remove elements while looping over a collection

Which loop to choose?

SituationUse
Known number of iterationsfor
Unknown iterations, may run zero timeswhile
Must run at least once (menus, input validation)do-while
Visit every element of an array or collectionfor-each

03Jump Statements

StatementEffect
breakExits the nearest loop or switch
continueSkips to the next iteration of the loop
returnExits the current method (optionally with a value)
break label / continue labelJumps out of or continues an outer loop
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // skip evens
    if (i > 7) break;           // stop at 7
    System.out.println(i);      // 1 3 5 7
}

Labelled break

outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i * j == 4) break outer;
        System.out.println(i + "," + j);
    }
}

05Common Programs

Factorial

long fact = 1;
for (int i = 2; i <= n; i++) fact *= i;

Prime check

boolean prime = n > 1;
for (int i = 2; i * i <= n; i++) {
    if (n % i == 0) { prime = false; break; }
}

Fibonacci (first 10)

int a = 0, b = 1;
for (int i = 0; i < 10; i++) {
    System.out.print(a + " ");
    int next = a + b;
    a = b;
    b = next;
}

Palindrome number

int original = n, reversed = 0;
while (n > 0) {
    reversed = reversed * 10 + n % 10;
    n /= 10;
}
boolean isPalindrome = (original == reversed);

06Common Mistakes

  • A semicolon right after if (...) or for (...) makes the body empty
  • Using = instead of == in conditions
  • Off-by-one errors: i <= n versus i < n
  • Forgetting break in classic switch
  • Infinite loops because the loop variable is never updated

07Quick Recap

  • if / else if / else for conditions; switch for many fixed choices
  • Prefer arrow-style switch expressions in modern Java
  • for, while, do-while, and for-each cover all looping needs
  • break leaves a loop, continue skips an iteration, labels reach outer loops
