REST APIs and Spring Boot

Build modern web services in Java. REST principles, JAX-RS, then Spring Boot with controllers, dependency injection, validation, exception handling, security and deployment.

01REST Fundamentals

REST (Representational State Transfer) is an architectural style for web APIs. Resources are identified by URLs and manipulated through standard HTTP methods; data is usually exchanged as JSON.

Principles

  • Client-server separation
  • Stateless: every request carries all needed information
  • Uniform interface: standard methods, URLs, status codes, representations
  • Resource-based: nouns in URLs, not verbs
  • Cacheable and layered

Designing URLs

ActionMethod + URLSuccess status
ListGET /api/students200
Read oneGET /api/students/5200 / 404
CreatePOST /api/students201 + Location header
ReplacePUT /api/students/5200 / 204
Partial updatePATCH /api/students/5200
DeleteDELETE /api/students/5204
NestedGET /api/courses/3/lessons200
Filter / page / sortGET /api/students?status=ACTIVE&page=0&size=20&sort=name,asc200

Use plural nouns, lowercase, no verbs (/students, not /getStudents). Version with /api/v1/....

Error responses

{
  "timestamp": "2026-10-06T09:30:00Z",
  "status": 400,
  "error": "Bad Request",
  "message": "email must be a valid email address",
  "path": "/api/students"
}

Prefer a consistent format; the standard Problem Details (RFC 9457) is supported by Spring.

02JAX-RS (Jakarta REST)

The Jakarta EE standard for REST. Implementations: Jersey, RESTEasy.

@ApplicationPath("/api")
public class RestApp extends Application { }

@Path("/students")
@Produces(MediaType.APPLICATION_JSON)
@Consumes(MediaType.APPLICATION_JSON)
public class StudentResource {

    @Inject StudentService service;

    @GET
    public List<Student> list(@QueryParam("status") String status) { return service.find(status); }

    @GET @Path("/{id}")
    public Response get(@PathParam("id") long id) {
        return service.find(id)
                .map(s -> Response.ok(s).build())
                .orElse(Response.status(Response.Status.NOT_FOUND).build());
    }

    @POST
    public Response create(@Valid StudentDto dto, @Context UriInfo uri) {
        Student s = service.create(dto);
        return Response.created(uri.getAbsolutePathBuilder().path(String.valueOf(s.getId())).build()).entity(s).build();
    }

    @DELETE @Path("/{id}")
    public Response delete(@PathParam("id") long id) { service.delete(id); return Response.noContent().build(); }
}

03Spring Boot

Spring Boot is the most widely used Java framework for building web services. It provides auto-configuration, an embedded server (Tomcat) and starter dependencies, so an app runs from a single jar with java -jar.

Core ideas

ConceptMeaning
IoC containerSpring creates and wires objects ("beans")
Dependency InjectionBeans receive their collaborators instead of creating them
Auto-configurationReasonable defaults based on what is on the classpath
StartersOne dependency pulls in a consistent set (spring-boot-starter-web)
ActuatorHealth, metrics, info endpoints

Create a project

Use start.spring.io (Spring Initializr): Maven, Java 21, dependencies Spring Web, Spring Data JPA, Validation, PostgreSQL Driver, Spring Security, Actuator.

@SpringBootApplication      // = @Configuration + @EnableAutoConfiguration + @ComponentScan
public class LmsApplication {
    public static void main(String[] args) {
        SpringApplication.run(LmsApplication.class, args);
    }
}

04Stereotype Annotations and Dependency Injection

AnnotationLayer
@ComponentGeneric bean
@ServiceBusiness logic
@RepositoryData access (adds exception translation)
@RestControllerWeb layer returning JSON
@Configuration + @BeanManual bean definitions
@Service
public class StudentService {
    private final StudentRepository repo;                  // constructor injection: preferred
    public StudentService(StudentRepository repo) { this.repo = repo; }
}
Tip

Prefer constructor injection. It makes dependencies explicit, supports final fields and makes testing trivial. Avoid field injection (@Autowired on fields).

Bean scopes

singleton (default), prototype, request, session, application.

05Building a REST Controller

@RestController
@RequestMapping("/api/v1/students")
public class StudentController {

    private final StudentService service;
    public StudentController(StudentService service) { this.service = service; }

    @GetMapping
    public Page<StudentResponse> list(@RequestParam(defaultValue = "") String q,
                                      @PageableDefault(size = 20, sort = "name") Pageable pageable) {
        return service.search(q, pageable);
    }

    @GetMapping("/{id}")
    public StudentResponse get(@PathVariable Long id) { return service.get(id); }

    @PostMapping
    public ResponseEntity<StudentResponse> create(@Valid @RequestBody StudentRequest req) {
        StudentResponse created = service.create(req);
        URI location = URI.create("/api/v1/students/" + created.id());
        return ResponseEntity.created(location).body(created);
    }

    @PutMapping("/{id}")
    public StudentResponse update(@PathVariable Long id, @Valid @RequestBody StudentRequest req) {
        return service.update(id, req);
    }

    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void delete(@PathVariable Long id) { service.delete(id); }
}

06DTOs and Validation

Never expose JPA entities directly. Use DTOs (records are ideal).

public record StudentRequest(
        @NotBlank @Size(max = 100) String name,
        @NotBlank @Email String email,
        @Min(5) @Max(100) Integer age) { }

public record StudentResponse(Long id, String name, String email) {
    static StudentResponse from(Student s) { return new StudentResponse(s.getId(), s.getName(), s.getEmail()); }
}

Common constraints: @NotNull, @NotBlank, @NotEmpty, @Size, @Min, @Max, @Pattern, @Email, @Past, @Positive.

07Global Exception Handling

@RestControllerAdvice
public class ApiExceptionHandler {

    @ExceptionHandler(StudentNotFoundException.class)
    public ProblemDetail notFound(StudentNotFoundException ex) {
        return ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ProblemDetail invalid(MethodArgumentNotValidException ex) {
        ProblemDetail pd = ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, "Validation failed");
        pd.setProperty("errors", ex.getBindingResult().getFieldErrors().stream()
                .collect(Collectors.toMap(FieldError::getField, FieldError::getDefaultMessage, (a, b) -> a)));
        return pd;
    }
}

09Spring Security (overview)

@Configuration
@EnableWebSecurity
public class SecurityConfig {
    @Bean
    SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http.csrf(csrf -> csrf.disable())                     // OK for stateless token APIs only
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(a -> a
                .requestMatchers("/api/v1/auth/**", "/actuator/health").permitAll()
                .requestMatchers(HttpMethod.DELETE, "/api/**").hasRole("ADMIN")
                .anyRequest().authenticated())
            .oauth2ResourceServer(o -> o.jwt(Customizer.withDefaults()));
        return http.build();
    }

    @Bean PasswordEncoder passwordEncoder() { return new BCryptPasswordEncoder(); }
}

Concepts: authentication (who are you?), authorization (what may you do?), roles/authorities, JWT bearer tokens, OAuth 2.0 / OIDC, method security (@PreAuthorize("hasRole('ADMIN')")), CORS configuration.

10Testing

@WebMvcTest(StudentController.class)
class StudentControllerTest {
    @Autowired MockMvc mvc;
    @MockBean StudentService service;

    @Test
    void getReturnsStudent() throws Exception {
        when(service.get(1L)).thenReturn(new StudentResponse(1L, "Asha", "a@x.com"));
        mvc.perform(get("/api/v1/students/1"))
           .andExpect(status().isOk())
           .andExpect(jsonPath("$.name").value("Asha"));
    }
}
AnnotationTests
@SpringBootTestWhole application context
@WebMvcTestController layer only
@DataJpaTestRepositories with an embedded DB
@MockBean / @MockitoBeanReplace a bean with a mock

Use Testcontainers to test against a real PostgreSQL.

15Microservices (brief)

Splitting an application into small services that communicate over HTTP or messaging (Kafka, RabbitMQ). Supporting tools: API gateway, service discovery, config server, circuit breakers (Resilience4j), distributed tracing (OpenTelemetry). Start with a well-structured monolith and split only when the team and scale need it.

17Quick Recap

  • REST uses nouns, HTTP methods and status codes; keep it stateless
  • Spring Boot = auto-configuration + embedded server + starters
  • @RestController → @Service → @Repository layering with constructor injection
  • Validate input with Bean Validation; return DTOs, not entities
  • Handle errors in one @RestControllerAdvice; secure with Spring Security
  • Package as a jar, configure through environment variables
