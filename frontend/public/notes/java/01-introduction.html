Introduction to Java

What Java is, why it is everywhere, how a program travels from source code to a running application, and how to write and run your first program.

01What is Java?

Java is a general-purpose, object-oriented, class-based programming language created at Sun Microsystems (now owned by Oracle). It is designed around one promise: "Write Once, Run Anywhere" (WORA). You compile your code once and the same compiled file runs on Windows, Linux or macOS, as long as a Java Virtual Machine is installed.

Where Java is used

  • Enterprise back-ends: banking, insurance, e-commerce, telecom
  • Android apps (Java and Kotlin)
  • Big-data tools: Hadoop, Kafka, Spark, Elasticsearch
  • Web services with Spring Boot and Jakarta EE
  • Desktop software, games (Minecraft), embedded systems, and financial trading systems

Why learn Java first?

  • Strongly typed, so the compiler catches many mistakes before the program runs
  • Massive ecosystem of libraries and frameworks
  • Automatic memory management (garbage collection)
  • Huge job market and long-term backward compatibility

02History and Versions

Java was started in 1991 by James Gosling's team ("Green Project", first named Oak) and released publicly as Java 1.0 in 1996. Since Java 9, a new feature release arrives every six months, and a release every two years is marked LTS (Long-Term Support).

Tip

For learning and for most jobs, install Java 17 or Java 21. Both are LTS releases and are widely supported by frameworks.

03Features of Java

  • Simple: no pointers, no operator overloading, no multiple inheritance of classes
  • Object-oriented: everything lives inside classes (except primitives)
  • Platform independent: bytecode runs on any JVM
  • Secure: no direct memory access, bytecode verifier, security manager history, sandboxing
  • Robust: strong type checking, exception handling, garbage collection
  • Multithreaded: threads are built into the language and library
  • High performance: the JIT compiler turns hot bytecode into native machine code
  • Portable and distributed: networking and RMI support in the standard library
  • Dynamic: classes are loaded at runtime, reflection is supported

05How a Java Program Runs

  1. You write source code in a .java file.
  2. The compiler javac checks syntax and types and produces bytecode in a .class file.
  3. The class loader loads the .class file into the JVM.
  4. The bytecode verifier checks it is safe.
  5. The interpreter runs the bytecode; the JIT compiler converts frequently used code into native machine code for speed.
Hello.java  --javac-->  Hello.class (bytecode)  --JVM-->  Machine code  -->  Output

Compiled or interpreted?

Both. Java is compiled to bytecode and then interpreted/JIT-compiled by the JVM. That two-step design is what makes it portable and fast.

06Installing and Setting Up

  1. Download a JDK (Eclipse Temurin, Oracle JDK or Amazon Corretto).
  2. Set the JAVA_HOME environment variable to the JDK folder.
  3. Add JAVA_HOME/bin to your PATH.
  4. Verify in a terminal.
java -version
javac -version

Choosing an editor or IDE

  • IntelliJ IDEA (Community is free) is the most popular
  • Eclipse and NetBeans are free and widely used in colleges
  • VS Code with the Extension Pack for Java is lightweight

07Your First Program

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Hanbee!");
    }
}
javac Hello.java
java Hello
Hello, Hanbee!

Since Java 11 you can also run a single file directly with java Hello.java.

Anatomy of the program

PartMeaning
public class HelloDeclares a class. A public class must be in a file with the same name (Hello.java).
publicAccessible from anywhere, so the JVM can call it.
staticBelongs to the class, so the JVM can call it without creating an object.
voidThe method returns nothing.
mainThe entry point the JVM looks for.
String[] argsCommand-line arguments passed to the program.
System.out.printlnPrints a line to the standard output.
Warning

Java is case-sensitive. Main, main and MAIN are three different names. A common error is writing string instead of String.

10Common Beginner Errors

  • class Hello is public, should be declared in a file named Hello.java: file name must match the public class name
  • error: ';' expected: missing semicolon
  • cannot find symbol: a typo, a missing import or a variable used before it is declared
  • Error: Could not find or load main class: wrong class name or wrong folder when running java
  • 'javac' is not recognized: JDK bin folder is not on the PATH
Interview question

What is the difference between JDK, JRE and JVM? Why is Java platform independent but the JVM is not?

Java source compiles to platform-neutral bytecode, so the same .class file runs anywhere. The JVM itself is native code written per operating system, which is what interprets that bytecode.

11Quick Recap

  • Java compiles to bytecode, and the JVM runs it on any platform
  • JDK = tools + JRE; JRE = libraries + JVM
  • Program entry point is public static void main(String[] args)
  • File name must match the public class name
  • Use LTS versions (17, 21) for learning and projects
