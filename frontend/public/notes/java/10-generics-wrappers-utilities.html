Generics, Wrapper Classes and Utility APIs

Type-safe code with generics, boxing and unboxing of primitives, plus the everyday utility classes Math, Objects, Random and the java.time date-time API.

01Wrapper Classes

Every primitive has an object counterpart in java.lang. Collections and generics only work with objects, so wrappers are essential.

PrimitiveWrapper
byte short int longByte Short Integer Long
float doubleFloat Double
charCharacter
booleanBoolean
int a = Integer.parseInt("42");            // String → int
Integer b = Integer.valueOf("42");         // String → Integer
String s = Integer.toString(42);           // int → String
int max = Integer.MAX_VALUE;
int cmp = Integer.compare(3, 5);           // -1
String bin = Integer.toBinaryString(10);   // "1010"
boolean digit = Character.isDigit('7');

Autoboxing and unboxing

Integer boxed = 10;        // autoboxing: int → Integer
int plain = boxed;         // unboxing:  Integer → int
List<Integer> list = new ArrayList<>();
list.add(5);               // boxing happens automatically
Warning

Unboxing a null wrapper throws NullPointerException. Boxing in tight loops also creates garbage; prefer primitives for heavy computation.

The Integer cache trap

Integer x = 127, y = 127;
System.out.println(x == y);        // true  (cached range -128..127)
Integer p = 1000, q = 1000;
System.out.println(p == q);        // false (different objects)
System.out.println(p.equals(q));   // true

Always compare wrapper objects with equals().

02Generics

Generics let classes and methods work with type parameters, giving compile-time type safety and removing casts.

// Without generics (old, unsafe)
List raw = new ArrayList();
raw.add("hi");
Integer n = (Integer) raw.get(0);     // ClassCastException at runtime

// With generics
List<String> names = new ArrayList<>();
names.add("hi");
// names.add(5);                      // compile error
String first = names.get(0);          // no cast

Generic classes

public class Box<T> {
    private T value;
    public Box(T value) { this.value = value; }
    public T get() { return value; }
    public void set(T value) { this.value = value; }
}

Box<String> b = new Box<>("Java");
Box<Integer> n = new Box<>(10);

Conventional names: T (type), E (element), K (key), V (value), N (number), R (result).

Generic methods

public static <T> void printAll(List<T> items) {
    for (T item : items) System.out.println(item);
}

public static <T extends Comparable<T>> T max(T a, T b) {
    return a.compareTo(b) >= 0 ? a : b;
}

Bounded type parameters

class Stats<N extends Number> {          // N must be Number or a subclass
    private final List<N> nums;
    Stats(List<N> nums) { this.nums = nums; }
    double sum() {
        double s = 0;
        for (N n : nums) s += n.doubleValue();
        return s;
    }
}

Multiple bounds: <T extends Number & Comparable<T>>.

Wildcards

SyntaxMeaningUse
List<?>List of unknown typeRead-only, any type
List<? extends Number>Number or a subtypeProducer: read from it
List<? super Integer>Integer or a supertypeConsumer: write to it
double sum(List<? extends Number> list) {     // accepts List<Integer>, List<Double> ...
    double total = 0;
    for (Number n : list) total += n.doubleValue();
    return total;
}
void fill(List<? super Integer> list) { list.add(1); }
Tip

Remember PECS: Producer Extends, Consumer Super.

Type erasure and limitations

Generic type information exists only at compile time. At runtime List<String> and List<Integer> are both List.

  • Cannot use primitives: List<int> is invalid, use List<Integer>
  • Cannot create new T() or new T[10]
  • Cannot use instanceof List<String>
  • Static members cannot use the class type parameter
  • List<Object> is not a supertype of List<String> (generics are invariant)

03Math and Number Utilities

Math.abs(-5);          Math.pow(2, 10);       Math.sqrt(49);
Math.max(3, 8);        Math.min(3, 8);
Math.ceil(4.1);        // 5.0
Math.floor(4.9);       // 4.0
Math.round(4.5);       // 5
Math.random();         // [0.0, 1.0)
Math.floorMod(-7, 3);  // 2
Math.addExact(a, b);   // throws ArithmeticException on overflow

BigInteger and BigDecimal

BigDecimal price = new BigDecimal("19.99");
BigDecimal total = price.multiply(new BigDecimal("3")).setScale(2, RoundingMode.HALF_UP);
BigInteger big = BigInteger.valueOf(2).pow(100);
Warning

Always build BigDecimal from a String, not a double. new BigDecimal(0.1) carries the binary rounding error.

04Objects and Random

Objects.equals(a, b);                 // null-safe equals
Objects.hash(id, name);               // hashCode helper
Objects.requireNonNull(x, "x is required");
Objects.toString(obj, "default");
Objects.requireNonNullElse(x, "fallback");

Random r = new Random();
int dice = r.nextInt(6) + 1;          // 1..6
int n = ThreadLocalRandom.current().nextInt(1, 101);   // 1..100, concurrency-friendly

Use SecureRandom for passwords, tokens and anything security-related.

05java.time: Date and Time API (Java 8)

The old Date and Calendar are mutable and confusing. Use the immutable java.time classes.

ClassRepresents
LocalDateDate without time (2026-10-06)
LocalTimeTime without date
LocalDateTimeDate and time, no zone
ZonedDateTimeDate, time and zone
InstantA moment on the UTC timeline (machine time)
DurationTime-based amount (hours, seconds)
PeriodDate-based amount (years, months, days)
LocalDate today = LocalDate.now();
LocalDate dob = LocalDate.of(2005, Month.MARCH, 14);
LocalDate next = today.plusDays(10).withDayOfMonth(1);
long age = ChronoUnit.YEARS.between(dob, today);
Period p = Period.between(dob, today);

06Other Handy Classes

  • Optional<T>: a container that may or may not hold a value (covered with Streams)
  • UUID.randomUUID(): unique identifiers
  • System.currentTimeMillis() and System.nanoTime(): timing
  • Scanner, StringJoiner, Locale, Currency
  • Runtime.getRuntime(): memory and processor info

07Quick Recap

  • Wrappers box primitives; compare them with equals(), beware null unboxing
  • Generics add compile-time type safety; erased at runtime
  • Use ? extends to read, ? super to write (PECS)
  • Use BigDecimal for money and java.time for dates
