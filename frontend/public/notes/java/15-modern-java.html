Modern Java (Java 9 to 25)

A tour of the language and library features added since Java 8, including var, text blocks, records, sealed types, pattern matching and virtual threads.

01Why Keep Up?

Since Java 9 a new version ships every six months, and every fourth release is LTS (11, 17, 21, 25). Modern Java is much more concise than the Java 8 many tutorials still show.

02Java 9 to 11

Module system (Java 9)

module com.hanbee.lms {
    requires java.sql;
    exports com.hanbee.lms.api;
}

Modules give strong encapsulation and reliable dependencies. Most applications still use the classpath; modules matter more for libraries and jlink.

Convenience factories

List<String> list = List.of("a", "b");
Set<Integer> set = Set.of(1, 2, 3);
Map<String, Integer> map = Map.of("a", 1, "b", 2);
// all immutable: add/put throws UnsupportedOperationException

Other additions

  • JShell: interactive REPL (jshell command)
  • Private interface methods, Optional.ifPresentOrElse, Stream.takeWhile/dropWhile
  • try-with-resources on an effectively final variable
  • var for local variables (Java 10)
  • New HttpClient (Java 11), String.isBlank/strip/lines/repeat, Files.readString
  • Run a source file directly: java Hello.java

03var (Java 10)

var users = new ArrayList<User>();
for (var u : users) { ... }
var stream = users.stream().map(User::name);

Use var when the type is obvious from the right-hand side. Avoid it when it hides meaning.

04Java 12 to 17

Switch expressions (Java 14)

int days = switch (month) {
    case JAN, MAR, MAY, JUL, AUG, OCT, DEC -> 31;
    case APR, JUN, SEP, NOV -> 30;
    case FEB -> leap ? 29 : 28;
};

Text blocks (Java 15)

String html = """
    <div class="card">
      <h2>%s</h2>
    </div>
    """.formatted(title);

Records (Java 16)

public record Point(int x, int y) { }

Immutable data classes with constructor, accessors, equals, hashCode and toString generated.

Pattern matching for instanceof (Java 16)

if (obj instanceof String s && s.length() > 3) {
    System.out.println(s.toUpperCase());
}

Sealed classes (Java 17)

public sealed interface Payment permits Card, Upi, Cash { }
public record Card(String number) implements Payment { }
public record Upi(String id) implements Payment { }
public record Cash() implements Payment { }

Helpful NPE messages (Java 14+)

NullPointerException now says exactly which variable or call was null.

Other

  • Stream.toList() (Java 16)
  • Strong encapsulation of JDK internals (Java 17)
  • Removal of the Security Manager and Applet API

05Java 18 to 21

Pattern matching for switch (Java 21)

static String format(Object o) {
    return switch (o) {
        case null -> "null";
        case Integer i when i > 0 -> "positive " + i;
        case Integer i -> "int " + i;
        case String s -> "text " + s;
        case Point(int x, int y) -> "point " + x + "," + y;     // record pattern
        default -> o.toString();
    };
}

Record patterns (Java 21)

if (shape instanceof Rect(Point(var x1, var y1), Point(var x2, var y2))) {
    System.out.println(Math.abs(x2 - x1));
}

Virtual threads (Java 21)

try (var ex = Executors.newVirtualThreadPerTaskExecutor()) {
    ex.submit(() -> handleRequest());
}

Sequenced collections (Java 21)

List<String> l = new ArrayList<>(List.of("a", "b", "c"));
l.getFirst();   l.getLast();   l.reversed();   l.addFirst("z");

Other

  • UTF-8 as the default charset (Java 18)
  • Simple web server: jwebserver
  • Generational ZGC

06Java 22 to 25

Highlights (some were previews on the way; check the release you use):

  • Unnamed variables and patterns _ for values you ignore: catch (Exception _), case Point(var x, _)
  • Stream Gatherers: custom intermediate stream operations
  • Scoped values and structured concurrency: safer concurrent code (finalised or maturing, see the JEP status)
  • Flexible constructor bodies, module import declarations
  • Compact source files and instance main methods for beginners:
void main() {
    IO.println("Hello, Java!");
}
  • Foreign Function & Memory API replaces most JNI use
  • Class-File API, Markdown in Javadoc, Stream improvements
Note

Preview features need --enable-preview and can change. Check the current JEP page before relying on one in production.

08Migrating and Best Practices

  • Move to the latest LTS your framework supports (Spring Boot 3+ requires Java 17+)
  • Replace verbose DTOs and value classes with record
  • Replace if instanceof chains and visitor patterns with sealed types + pattern switch
  • Replace manual thread pools for I/O-bound services with virtual threads
  • Use var selectively, text blocks for SQL/JSON/HTML

09Quick Recap

  • Java releases every 6 months; target LTS versions
  • Records, sealed types and pattern matching make data modelling concise and safe
  • Switch is now an expression with pattern matching
  • Virtual threads simplify high-concurrency servers
