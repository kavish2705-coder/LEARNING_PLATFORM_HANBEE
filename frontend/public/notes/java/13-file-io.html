File I/O, NIO and Serialization

Read and write files with the java.io streams, the modern java.nio.file API, and persist objects with serialization.

01I/O Basics

Java I/O is built on the idea of a stream: an ordered flow of data from a source to a destination.

Byte streamsCharacter streams
Unit8-bit bytes16-bit characters
Base classesInputStream / OutputStreamReader / Writer
Use forImages, audio, any binaryText
ExamplesFileInputStream, BufferedOutputStreamFileReader, BufferedWriter

Standard streams: System.in (input), System.out (output), System.err (errors).

02The File Class

Represents a path to a file or directory (not its content).

File f = new File("notes/data.txt");
f.exists();   f.isFile();   f.isDirectory();   f.length();
f.getName();  f.getParent();   f.getAbsolutePath();
f.createNewFile();   f.mkdirs();   f.delete();
String[] names = new File("notes").list();

03Reading and Writing Text (java.io)

Reading line by line

try (BufferedReader br = new BufferedReader(new FileReader("data.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}

Writing

try (BufferedWriter bw = new BufferedWriter(new FileWriter("out.txt", true))) {   // true = append
    bw.write("Hello");
    bw.newLine();
}
try (PrintWriter pw = new PrintWriter("report.txt")) {
    pw.printf("Total: %d%n", 42);
}

Binary data

try (InputStream in = new BufferedInputStream(new FileInputStream("a.jpg"));
     OutputStream out = new BufferedOutputStream(new FileOutputStream("copy.jpg"))) {
    byte[] buffer = new byte[8192];
    int n;
    while ((n = in.read(buffer)) != -1) out.write(buffer, 0, n);
}
Tip

Always wrap in Buffered* classes: it cuts expensive disk calls. Always use try-with-resources.

Decorator pattern in java.io

Streams wrap each other to add behaviour: new BufferedReader(new InputStreamReader(new FileInputStream(f), UTF_8)).

Specifying the character set

new InputStreamReader(new FileInputStream("a.txt"), StandardCharsets.UTF_8);

04NIO.2: java.nio.file (Java 7+)

The modern, simpler API. Prefer it for new code.

Path path = Path.of("data", "notes.txt");              // or Paths.get(...)
path.getFileName();  path.getParent();  path.toAbsolutePath();  path.resolve("x.txt");

String content = Files.readString(path);                       // Java 11+
List<String> lines = Files.readAllLines(path);
Files.writeString(path, "Hello\n", StandardOpenOption.CREATE, StandardOpenOption.APPEND);
Files.write(path, lines);

Files.exists(path);   Files.isDirectory(path);   Files.size(path);
Files.createDirectories(Path.of("a/b/c"));
Files.copy(src, dest, StandardCopyOption.REPLACE_EXISTING);
Files.move(src, dest);
Files.delete(path);   Files.deleteIfExists(path);

try (Stream<String> s = Files.lines(path)) {                  // lazy, for large files
    s.filter(l -> l.contains("ERROR")).forEach(System.out::println);
}
try (Stream<Path> files = Files.walk(Path.of("project"))) {   // recursive listing
    files.filter(p -> p.toString().endsWith(".java")).forEach(System.out::println);
}
try (DirectoryStream<Path> ds = Files.newDirectoryStream(dir, "*.txt")) { ... }

06Serialization

Serialization converts an object's state into a byte stream; deserialization rebuilds it. Used for saving, caching and (historically) network transfer.

class User implements Serializable {
    private static final long serialVersionUID = 1L;
    String name;
    transient String password;     // transient fields are skipped
    static int counter;            // static fields are not serialised
}

// write
try (ObjectOutputStream out = new ObjectOutputStream(new FileOutputStream("user.ser"))) {
    out.writeObject(new User());
}
// read
try (ObjectInputStream in = new ObjectInputStream(new FileInputStream("user.ser"))) {
    User u = (User) in.readObject();
}

Rules

  • Class must implement the marker interface Serializable
  • All non-transient fields must be serializable too (else NotSerializableException)
  • serialVersionUID is the version stamp: mismatch causes InvalidClassException
  • If a parent class is not serializable, it needs an accessible no-arg constructor
  • Constructors are not called during deserialization
Warning

Deserializing untrusted data is a serious security risk (remote code execution). For data exchange prefer JSON (Jackson/Gson) or similar text formats, and use ObjectInputFilter if you must deserialize.

07Working with JSON (brief)

Real applications use a library such as Jackson.

ObjectMapper mapper = new ObjectMapper();
String json = mapper.writeValueAsString(user);
User back = mapper.readValue(json, User.class);

09Quick Recap

  • Byte streams for binary, character streams for text; wrap with Buffered*
  • Prefer Path and Files (NIO.2) for new code
  • Always close resources with try-with-resources
  • Use transient for fields that must not be serialised
  • Avoid native Java serialization for untrusted or long-lived data; use JSON
