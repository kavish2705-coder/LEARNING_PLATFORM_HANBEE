JSP, Expression Language and JSTL

Build the view layer with JavaServer Pages. JSP lifecycle, directives, implicit objects, Expression Language, JSTL tags and custom tags.

01What is JSP?

JavaServer Pages let you write HTML with embedded dynamic content. The container translates each JSP into a servlet the first time it is requested, compiles it and runs it. Servlets are great for logic; JSP is better for presentation.

index.jsp ──translate──► index_jsp.java (a servlet) ──compile──► .class ──► response

Servlet vs JSP

ServletJSP
Looks likeJava with HTML in stringsHTML with Java/tags inside
Best forControllers, logicViews
Edit & reloadRecompile neededAuto-recompiled by container

02JSP Lifecycle

  1. Translation: JSP → servlet source
  2. Compilation: servlet source → class
  3. Loading and instantiation
  4. jspInit(): once
  5. _jspService(): every request
  6. jspDestroy(): once

03JSP Elements

ElementSyntaxPurpose
Directive<%@ ... %>Page-level instructions
Scriptlet<% ... %>Java code (avoid)
Expression<%= expr %>Print a value (avoid, use EL)
Declaration<%! ... %>Fields/methods (avoid)
Comment<%-- hidden --%>Not sent to the browser
Action<jsp:include .../>Built-in tags
EL${...}Preferred way to output data
JSTL<c:forEach>Preferred logic tags
Warning

Scriptlets (<% %>) mix logic into the view and make pages hard to test and maintain. Modern JSP uses only EL + JSTL. Do business logic in servlets/services.

07Expression Language (EL)

${expression} reads data from scopes and prints it HTML-safe when used with <c:out> (EL alone does not escape).

${student.name}                    <%-- property → getName() --%>
${students[0].email}               <%-- list index --%>
${marks['math']}                   <%-- map key --%>
${param.q}                         <%-- request parameter --%>
${header['User-Agent']}
${cookie.theme.value}
${sessionScope.user.name}
${requestScope.error}
${applicationScope.appName}
${pageContext.request.contextPath}
${empty students}                  <%-- true if null, empty string, empty collection --%>
${age >= 18 ? 'Adult' : 'Minor'}
${price * qty}      ${a and b}      ${not done}      ${x eq y}   ${x ne y}
  • EL searches scopes in order: page → request → session → application
  • Missing values print as empty, not errors
  • Operators: arithmetic, ==/eq, !=/ne, </lt, &&/and, ||/or, !/not, empty, ?:

08JSTL (JSP Standard Tag Library)

Add the dependency (jakarta.servlet.jsp.jstl) and declare the taglib.

Core tags (c:)

<c:out value="${comment}" />                                  <%-- HTML-escapes: prevents XSS --%>

<c:set var="total" value="${price * qty}" scope="request" />
<c:remove var="temp" />

<c:if test="${not empty error}">
  <p class="error"><c:out value="${error}" /></p>
</c:if>

<c:choose>
  <c:when test="${score >= 90}">A</c:when>
  <c:when test="${score >= 60}">B</c:when>
  <c:otherwise>Fail</c:otherwise>
</c:choose>

<c:forEach var="s" items="${students}" varStatus="st">
  <tr class="${st.index % 2 == 0 ? 'even' : 'odd'}">
    <td>${st.count}</td>
    <td><c:out value="${s.name}" /></td>
  </tr>
</c:forEach>

<c:forEach begin="1" end="5" var="i">${i} </c:forEach>
<c:forTokens items="a,b,c" delims="," var="t">${t}</c:forTokens>

<c:url value="/students" var="listUrl"><c:param name="page" value="2" /></c:url>
<a href="${listUrl}">Next</a>
<c:redirect url="/login" />
<c:import url="/fragments/footer.jsp" />
<c:catch var="ex"> ... </c:catch>

Formatting tags (fmt:)

<fmt:formatNumber value="${price}" type="currency" currencyCode="INR" />
<fmt:formatNumber value="${ratio}" type="percent" />
<fmt:formatDate value="${date}" pattern="dd MMM yyyy" />
<fmt:message key="welcome.title" />            <%-- i18n from a resource bundle --%>
<fmt:setLocale value="en_IN" />

Functions (fn:)

<%@ taglib prefix="fn" uri="jakarta.tags.functions" %>
${fn:length(students)}   ${fn:toUpperCase(name)}   ${fn:contains(email, '@')}   ${fn:substring(text, 0, 20)}

SQL tags

<sql:query> exist but should not be used: keep SQL out of the view.

09MVC with Servlet + JSP

Browser ─► Controller (Servlet) ─► Service/DAO ─► Model (JavaBeans)
              │                                        │
              └────────── forward ──► View (JSP) ◄─────┘
// Controller
@WebServlet("/students")
public class StudentListServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        req.setAttribute("students", studentService.findAll());
        req.getRequestDispatcher("/WEB-INF/views/students.jsp").forward(req, resp);
    }
}
<%-- /WEB-INF/views/students.jsp --%>
<%@ page contentType="text/html;charset=UTF-8" %>
<%@ taglib prefix="c" uri="jakarta.tags.core" %>
<html>
<body>
  <h1>Students (${students.size()})</h1>
  <c:choose>
    <c:when test="${empty students}"><p>No students yet.</p></c:when>
    <c:otherwise>
      <table>
        <c:forEach var="s" items="${students}">
          <tr><td><c:out value="${s.name}" /></td><td><c:out value="${s.email}" /></td></tr>
        </c:forEach>
      </table>
    </c:otherwise>
  </c:choose>
</body>
</html>

Put JSPs under WEB-INF/views so users cannot open them directly; only the controller forwards to them.

10JavaBeans

A JavaBean is a plain class with a no-arg constructor, private properties and getters/setters (getName/setName, isActive for booleans). EL and frameworks rely on this convention.

11Custom Tags (brief)

Tag files (simplest)

<%-- /WEB-INF/tags/card.tag --%>
<%@ attribute name="title" required="true" %>
<div class="card"><h3>${title}</h3><jsp:doBody/></div>
<%@ taglib prefix="ui" tagdir="/WEB-INF/tags" %>
<ui:card title="Java">Core to advanced</ui:card>

Larger libraries use SimpleTagSupport classes with a .tld descriptor.

13JSP vs Modern Template Engines

JSPThymeleaf / FreeMarkerSPA (React) + JSON API
Natural templatesNoThymeleaf yesn/a
Spring Boot defaultNo (needs extra setup)Yesn/a
Where usedLegacy and enterpriseNew server-rendered appsMost new products

JSP is still common in existing enterprise code, so it is important to understand; new projects often choose Thymeleaf or a separate front-end.

14Quick Recap

  • JSP is translated into a servlet; use it only for views
  • Use EL + JSTL, not scriptlets
  • <c:out> escapes HTML and protects against XSS
  • Controller servlet sets request attributes, then forwards to a JSP under WEB-INF
  • Know the implicit objects and the four scopes
