Arrays and Strings

Store collections of values in arrays, then master Java's most used class, String, along with StringBuilder, the string pool and regular expressions.

01Arrays

An array is a fixed-size, ordered container of elements of the same type, accessed by a zero-based index. Arrays are objects, stored on the heap.

Declaring and creating

int[] marks = new int[5];            // five zeros
int[] scores = {90, 80, 70};         // literal
String[] names = new String[3];      // three nulls
int size = scores.length;            // length is a field, not a method

Accessing and traversing

scores[0] = 95;
for (int i = 0; i < scores.length; i++) {
    System.out.println(scores[i]);
}
for (int s : scores) {
    System.out.println(s);
}
Warning

Accessing an invalid index throws ArrayIndexOutOfBoundsException. Valid indexes are 0 to length - 1.

Default values

Numeric arrays start with 0, boolean with false, char with '\u0000', and object arrays with null.

02Multi-dimensional Arrays

int[][] grid = new int[3][4];       // 3 rows, 4 columns
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(matrix[1][2]);   // 6

Jagged arrays

Rows can have different lengths.

int[][] jagged = new int[3][];
jagged[0] = new int[]{1};
jagged[1] = new int[]{1, 2};
jagged[2] = new int[]{1, 2, 3};

03The Arrays Utility Class

import java.util.Arrays;

int[] a = {5, 2, 9, 1};
Arrays.sort(a);                              // [1, 2, 5, 9]
int pos = Arrays.binarySearch(a, 5);         // 2 (array must be sorted)
int[] copy = Arrays.copyOf(a, 6);            // pads with zeros
int[] part = Arrays.copyOfRange(a, 1, 3);    // [2, 5]
Arrays.fill(a, 7);                           // [7, 7, 7, 7]
System.out.println(Arrays.toString(a));
System.out.println(Arrays.deepToString(new int[][]{{1}, {2, 3}}));
System.out.println(Arrays.equals(a, copy));
List<Integer> list = Arrays.asList(1, 2, 3); // fixed-size list view

04Strings

String is a class that represents a sequence of characters. It is immutable: once created, its content never changes. Every "modification" creates a new object.

String s1 = "Java";                 // string literal (goes to the pool)
String s2 = new String("Java");     // new object on the heap
char[] chars = {'J', 'a', 'v', 'a'};
String s3 = new String(chars);

The string pool

String literals are stored in a shared string constant pool. Two identical literals refer to the same object.

String a = "Hello";
String b = "Hello";
String c = new String("Hello");

System.out.println(a == b);        // true  (same pooled object)
System.out.println(a == c);        // false (different objects)
System.out.println(a.equals(c));   // true  (same content)
System.out.println(c.intern() == a); // true
Interview question

What is the difference between == and equals() for strings?

== compares references (are they the same object?). equals() compares content. Always use equals() to compare strings.

Why is String immutable?

  • Safe to share through the pool
  • Thread-safe without synchronisation
  • Safe as keys in HashMap (hash code is cached)
  • Security: file names, URLs and class names cannot be changed after validation

06StringBuilder and StringBuffer

Because String is immutable, building a string in a loop with + creates many throw-away objects. Use a mutable builder instead.

StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 5; i++) {
    sb.append(i).append(",");
}
sb.setLength(sb.length() - 1);     // remove last comma
sb.insert(0, "[").append("]");
sb.reverse();
System.out.println(sb);            // ]5,4,3,2,1[

Other methods: delete(start, end), deleteCharAt(i), replace(s, e, str), indexOf, charAt, toString().

07Regular Expressions

import java.util.regex.*;

boolean ok = "asha@mail.com".matches("[\\w.]+@[\\w.]+\\.[a-z]{2,}");

Pattern p = Pattern.compile("(\\d{3})-(\\d{4})");
Matcher m = p.matcher("Call 555-1234 now");
if (m.find()) {
    System.out.println(m.group());    // 555-1234
    System.out.println(m.group(1));   // 555
}
String clean = "a1b22c".replaceAll("[0-9]+", "#");   // a#b#c

08Common String Programs

// reverse
String rev = new StringBuilder(s).reverse().toString();

// palindrome
boolean pal = s.equalsIgnoreCase(rev);

// count vowels
long vowels = s.toLowerCase().chars().filter(c -> "aeiou".indexOf(c) >= 0).count();

// anagram check
char[] x = a.toCharArray(), y = b.toCharArray();
Arrays.sort(x); Arrays.sort(y);
boolean anagram = Arrays.equals(x, y);

09Quick Recap

  • Arrays are fixed-size, zero-indexed objects; use Arrays for sort/search/copy
  • String is immutable and pooled; compare with equals()
  • Use StringBuilder when building text in loops
  • split, matches and replaceAll accept regular expressions
