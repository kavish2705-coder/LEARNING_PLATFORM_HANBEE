Language Basics

Variables, data types, literals, operators, type casting and reading input. The building blocks every Java program is made from.

01Program Structure and Tokens

A Java source file is made of tokens: keywords, identifiers, literals, operators, separators and comments.

package com.hanbee.demo;          // 1. package (optional)

import java.util.Scanner;         // 2. imports (optional)

public class Demo {               // 3. class declaration
    public static void main(String[] args) {   // 4. methods
        int x = 10;               // 5. statements end with ;
    }
}

Keywords and identifiers

  • Keywords are reserved words such as class, int, if, for, static. They cannot be used as names.
  • Identifiers are names you choose for classes, variables and methods.
  • Rules: start with a letter, _ or $; may contain digits after the first character; cannot be a keyword; case-sensitive.

02Variables

A variable is a named memory location that holds a value of a declared type.

int age = 20;            // declaration + initialisation
double price;            // declaration only
price = 99.5;            // assignment later
int a = 1, b = 2, c = 3; // several at once
final double PI = 3.14159; // constant: cannot change

Types of variables

KindDeclaredLifetimeDefault value
LocalInside a method or blockUntil the block endsNone. Must be initialised before use.
InstanceInside a class, outside methodsAs long as the object lives0, false, null
Static (class)Inside a class with staticAs long as the class is loaded0, false, null

Scope

A variable is visible only inside the { } block where it is declared.

for (int i = 0; i < 3; i++) {
    int square = i * i;
}
// i and square are NOT accessible here

05Type Inference with var

From Java 10, the compiler can infer the type of a local variable.

var message = "Hello";           // String
var list = new ArrayList<String>(); // ArrayList<String>
Note

var is only for local variables with an initialiser. It is not a keyword and not dynamic typing: the type is still fixed at compile time.

06Operators

Arithmetic

+ - * / %. Integer division discards the fraction.

System.out.println(7 / 2);    // 3
System.out.println(7 % 2);    // 1
System.out.println(7 / 2.0);  // 3.5

Increment and decrement

int x = 5;
int a = x++;  // a = 5, x = 6  (post: use then increase)
int b = ++x;  // x = 7, b = 7  (pre: increase then use)

Assignment and compound assignment

= += -= *= /= %= &= |= ^= <<= >>= >>>=

Relational and logical

Ternary operator

int max = (a > b) ? a : b;

instanceof

if (obj instanceof String s) {   // pattern matching, Java 16+
    System.out.println(s.length());
}

Operator precedence (high to low)

  1. Postfix x++, parentheses, method calls
  2. Unary ++x, !, ~, -x
  3. Multiplicative * / %
  4. Additive + -
  5. Shift << >> >>>
  6. Relational < > <= >= instanceof
  7. Equality == !=
  8. &, then ^, then |
  9. &&, then ||
  10. Ternary ? :
  11. Assignment = += -=
Tip

When in doubt, use parentheses. They cost nothing and make intent obvious.

07Type Conversion and Casting

Widening (automatic)

A smaller type converts to a larger type with no data loss.

byte → short → int → long → float → double
              char → int
int i = 100;
double d = i;   // 100.0

Narrowing (explicit cast)

A larger type to a smaller type needs a cast and can lose data.

double d = 9.78;
int i = (int) d;        // 9 (fraction dropped)
int big = 130;
byte b = (byte) big;    // -126 (overflow wraps around)

Promotion in expressions

byte, short and char are promoted to int in arithmetic.

byte a = 10, b = 20;
// byte c = a + b;      // compile error: result is int
byte c = (byte) (a + b);
Warning

0.1 + 0.2 is not exactly 0.3 in floating point. For money use BigDecimal, never double.

Input with Scanner

import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter name: ");
        String name = sc.nextLine();
        System.out.print("Enter age: ");
        int age = sc.nextInt();
        System.out.println(name + " is " + age);
        sc.close();
    }
}
Warning

After nextInt() the newline stays in the buffer, so the next nextLine() returns an empty string. Call sc.nextLine() once to consume it.

Command-line arguments

public static void main(String[] args) {
    System.out.println(args.length + " arguments");
    for (String a : args) System.out.println(a);
}

09Integer Overflow and Special Values

int max = Integer.MAX_VALUE;
System.out.println(max + 1);        // -2147483648 (wraps around)
System.out.println(1.0 / 0);        // Infinity
System.out.println(0.0 / 0);        // NaN

Use Math.addExact() to throw an exception on overflow.

10Quick Recap

  • Eight primitives; everything else is a reference type
  • Local variables have no default value, fields do
  • Widening is automatic, narrowing needs a cast
  • && and || short-circuit, & and | do not
  • Use var for local inference, BigDecimal for money
