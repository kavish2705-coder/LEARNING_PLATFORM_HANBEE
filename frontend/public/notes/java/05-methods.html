Methods

Package reusable logic into methods. Parameters, return values, overloading, varargs, recursion and how Java passes arguments.

01What is a Method?

A method is a named block of code that performs one task and can be reused. It makes programs shorter, easier to test and easier to read.

accessModifier  [static]  returnType  methodName(parameters) {
    // body
    return value;   // if returnType is not void
}
public static int add(int a, int b) {
    return a + b;
}

public static void greet(String name) {
    System.out.println("Hello, " + name);
}

Calling a method

int total = add(5, 7);   // arguments: 5 and 7
greet("Asha");
TermMeaning
ParameterVariable in the method declaration (int a)
ArgumentActual value passed when calling (5)
Return typeType of the value sent back, or void for nothing
SignatureMethod name + parameter types (return type is not included)

02Static vs Instance Methods

  • A static method belongs to the class. Call it as ClassName.method(). It cannot use this or instance fields directly.
  • An instance method belongs to an object. You need an object to call it.
class MathUtil {
    static int square(int x) { return x * x; }       // MathUtil.square(4)
    int cube(int x) { return x * x * x; }            // new MathUtil().cube(3)
}

03Pass by Value

Java is always pass-by-value. A copy of the argument is passed.

Primitives

static void change(int x) { x = 99; }

int n = 10;
change(n);
System.out.println(n);   // 10 (unchanged)

Objects

The reference is copied. The method can modify the object the reference points to, but cannot make the caller's variable point to a different object.

static void modify(int[] arr) { arr[0] = 99; }       // changes the shared array
static void reassign(int[] arr) { arr = new int[]{1}; } // no effect on caller

int[] data = {1, 2, 3};
modify(data);
System.out.println(data[0]);   // 99
reassign(data);
System.out.println(data[0]);   // still 99
Interview question

Is Java pass-by-value or pass-by-reference?

Always pass-by-value. For objects, the value that is copied is the reference, which is why changes to the object's state are visible to the caller but reassigning the parameter is not.

04Method Overloading

Several methods with the same name but different parameter lists in one class. This is compile-time (static) polymorphism.

static int add(int a, int b)           { return a + b; }
static double add(double a, double b)  { return a + b; }
static int add(int a, int b, int c)    { return a + b + c; }

Overloading differs by number, type or order of parameters. Changing only the return type is not allowed.

How the compiler picks one

  1. Exact match
  2. Widening (int → long → double)
  3. Boxing (int → Integer)
  4. Varargs
static void show(long x)    { System.out.println("long"); }
static void show(Integer x) { System.out.println("Integer"); }
show(5);    // prints "long" (widening beats boxing)

05Varargs

A method can accept any number of arguments of one type using .... The parameter behaves as an array and must be the last parameter.

static int sum(int... numbers) {
    int total = 0;
    for (int n : numbers) total += n;
    return total;
}

sum();            // 0
sum(1, 2, 3);     // 6

06Returning Values

  • return ends the method immediately
  • A non-void method must return on every path
  • Only one value can be returned; return an array, a list or an object to return several
static int[] minMax(int[] a) {
    int min = a[0], max = a[0];
    for (int x : a) {
        if (x < min) min = x;
        if (x > max) max = x;
    }
    return new int[]{min, max};
}

07Recursion

A method that calls itself. Every recursive method needs a base case (stops) and a recursive case (moves toward the base case).

static long factorial(int n) {
    if (n <= 1) return 1;            // base case
    return n * factorial(n - 1);     // recursive case
}
factorial(4) → 4 * factorial(3)
                    → 3 * factorial(2)
                         → 2 * factorial(1) → 1
static int fib(int n) {
    return n < 2 ? n : fib(n - 1) + fib(n - 2);   // simple but slow: O(2^n)
}

static int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
Warning

Missing or unreachable base case causes StackOverflowError. Java does not optimise tail recursion; for very deep recursion use a loop.

08Method Best Practices

  • One method, one job; keep methods short
  • Use verbs for names: calculateTotal, isValid, getName
  • Prefer few parameters (3 or fewer); group more into an object
  • Avoid changing parameters; do not use output parameters
  • Document public methods with Javadoc

09The main Method

public static void main(String[] args)

main can be overloaded, but the JVM only starts with the exact signature above. In recent Java versions (preview in 21+), simplified instance main methods are being introduced for beginners.

10Quick Recap

  • A method has a name, parameters, a return type and a body
  • Java passes copies: primitives by value, object references by value
  • Overloading = same name, different parameters (resolved at compile time)
  • Varargs take zero or more arguments as an array
  • Recursion needs a base case; mind the stack depth
