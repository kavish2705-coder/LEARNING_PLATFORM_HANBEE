Interfaces, Enums, Records and Nested Classes

Define contracts with interfaces, model fixed sets with enums, write data classes with records, and use inner, local and anonymous classes.

01Interfaces

An interface is a contract: it declares what a class can do, without saying how. A class implements one or more interfaces.

interface Payable {
    double MAX_LIMIT = 100000;          // implicitly public static final
    void pay(double amount);            // implicitly public abstract
}

class UpiPayment implements Payable {
    @Override
    public void pay(double amount) {
        System.out.println("Paid " + amount + " via UPI");
    }
}

Payable p = new UpiPayment();
p.pay(500);

Why interfaces?

  • Achieve 100% abstraction and loose coupling
  • A class can implement many interfaces (multiple inheritance of type)
  • Program to the interface, not the implementation: swap implementations without changing callers

Interface inheritance

interface Readable { void read(); }
interface Writable { void write(); }
interface Storage extends Readable, Writable { }   // interfaces can extend many

02Default, Static and Private Methods

Added in Java 8/9 so interfaces can evolve without breaking existing implementations.

interface Greeter {
    String name();

    default String greet() {                 // inherited by implementors, may be overridden
        return prefix() + name();
    }

    private String prefix() {                // Java 9+, helper for default methods
        return "Hello, ";
    }

    static Greeter of(String n) {            // called as Greeter.of("Asha")
        return () -> n;
    }
}
Warning

If a class implements two interfaces with the same default method, it must override it and can pick one with InterfaceName.super.method().

04Enums

An enum is a special class representing a fixed set of constants.

enum Day { MON, TUE, WED, THU, FRI, SAT, SUN }

Day d = Day.WED;
switch (d) {
    case SAT, SUN -> System.out.println("Weekend");
    default       -> System.out.println("Weekday");
}

for (Day x : Day.values()) System.out.println(x.name() + " " + x.ordinal());
Day parsed = Day.valueOf("FRI");

Enums with fields, constructors and methods

enum Level {
    LOW(1), MEDIUM(5), HIGH(10);

    private final int weight;
    Level(int weight) { this.weight = weight; }   // constructor is implicitly private
    public int getWeight() { return weight; }
}

Enums with abstract methods

enum Op {
    ADD { int apply(int a, int b) { return a + b; } },
    MUL { int apply(int a, int b) { return a * b; } };
    abstract int apply(int a, int b);
}
  • Enums extend java.lang.Enum, so they cannot extend another class but can implement interfaces
  • Use EnumMap and EnumSet for fast collections keyed by enum
  • Enums are the best way to implement a singleton

05Records (Java 16+)

A record is a compact immutable data carrier. The compiler generates the constructor, accessors, equals, hashCode and toString.

public record Student(int id, String name) { }

Student s = new Student(1, "Asha");
System.out.println(s.name());     // accessor (no "get" prefix)
System.out.println(s);            // Student[id=1, name=Asha]

Compact constructor and extra members

public record Range(int from, int to) {
    public Range {                          // compact constructor: validation
        if (from > to) throw new IllegalArgumentException("from > to");
    }
    public int length() { return to - from; }
    public static Range of(int a, int b) { return new Range(a, b); }
}
  • Fields are private final; records are implicitly final
  • Cannot extend a class but can implement interfaces
  • Ideal for DTOs, API responses, map keys and tuples

06Sealed Classes (Java 17+)

Control exactly which classes may extend a type.

public sealed interface Shape permits Circle, Square { }
public record Circle(double r) implements Shape { }
public record Square(double side) implements Shape { }

double area(Shape s) {
    return switch (s) {                       // exhaustive, no default needed
        case Circle c -> Math.PI * c.r() * c.r();
        case Square q -> q.side() * q.side();
    };
}

07Nested and Inner Classes

A class declared inside another class. Use when the helper is only meaningful inside its outer class.

TypeDeclaredNeeds outer instance?
Static nestedstatic class inside a classNo
Inner (member)class inside a classYes
LocalInside a methodYes (captures effectively final locals)
AnonymousUnnamed, created inlineYes
class Outer {
    private int x = 10;

    static class StaticNested {            // new Outer.StaticNested()
        void hi() { System.out.println("static nested"); }
    }

    class Inner {                          // outer.new Inner()
        void show() { System.out.println(x); }   // can access outer's private members
    }
}

Outer o = new Outer();
Outer.Inner in = o.new Inner();

Anonymous classes

Runnable r = new Runnable() {
    @Override public void run() { System.out.println("running"); }
};

Prefer a lambda when the type is a functional interface.

08Quick Recap

  • Interfaces define contracts; classes can implement many
  • default, static and private interface methods allow evolution
  • Enums model fixed constants and can carry data and behaviour
  • Records are immutable data classes with generated boilerplate
  • Sealed types limit hierarchies and enable exhaustive switch
  • Nested classes keep helpers close; anonymous classes are mostly replaced by lambdas
