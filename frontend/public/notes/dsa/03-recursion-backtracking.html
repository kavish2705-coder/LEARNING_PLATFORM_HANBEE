Recursion and Backtracking

Learn to think recursively. Base and recursive cases, the call stack, memoisation, divide and conquer, and the backtracking template for subsets, permutations, combinations and N-Queens.

01What is Recursion?

A function that calls itself on a smaller version of the same problem. Every recursive solution has:

  1. Base case: the smallest problem you can answer directly (stops the recursion)
  2. Recursive case: reduce the problem and call yourself
  3. Progress: each call must move toward the base case
static long factorial(int n) {
    if (n <= 1) return 1;                 // base case
    return n * factorial(n - 1);          // recursive case
}
Warning

A missing base case, or a recursive call that never gets closer to it, ends in StackOverflowError.

02The Call Stack

Each call gets its own stack frame holding its parameters and local variables. Frames are pushed as calls go deeper and popped as they return.

factorial(4)
 └─ 4 * factorial(3)
        └─ 3 * factorial(2)
               └─ 2 * factorial(1)
                      └─ returns 1
               ← returns 2
        ← returns 6
 ← returns 24
  • Time: number of calls × work per call
  • Space: maximum recursion depth (call-stack frames)
  • Java's default stack allows roughly 10,000 to 20,000 frames; deeper recursion needs iteration or an explicit stack
  • Java does not do tail-call optimisation

03Thinking Recursively

Ask three questions:

  1. What is the smallest input and its answer? → base case
  2. If I could solve a smaller input, how would I use that answer? → recursive step (trust the recursion)
  3. Does every call get smaller? → termination

Examples

// Sum of digits
static int sumDigits(int n) { return n == 0 ? 0 : n % 10 + sumDigits(n / 10); }

// Power: O(n)
static long power(long x, int n) { return n == 0 ? 1 : x * power(x, n - 1); }

// Fast power (exponentiation by squaring): O(log n)
static long fastPower(long x, int n) {
    if (n == 0) return 1;
    long half = fastPower(x, n / 2);
    return n % 2 == 0 ? half * half : half * half * x;
}

// Reverse a string
static String reverse(String s) { return s.isEmpty() ? "" : reverse(s.substring(1)) + s.charAt(0); }

// Palindrome check
static boolean isPal(String s, int l, int r) {
    if (l >= r) return true;
    return s.charAt(l) == s.charAt(r) && isPal(s, l + 1, r - 1);
}

// GCD (Euclid)
static int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }

// Sum of an array
static int sum(int[] a, int i) { return i == a.length ? 0 : a[i] + sum(a, i + 1); }

04Recursion Tree and Complexity

Draw the calls as a tree: total work = the sum of the work at every node.

├── fib(3)
│    ├── fib(2)
│    │    ├── fib(1)
│    │    └── fib(0)
│    └── fib(1)
└── fib(2)
     ├── fib(1)
     └── fib(0)         fib(2) is computed twice: overlapping subproblems

05Memoisation: Remove Repeated Work

Cache results of calls so each distinct input is computed once. This is top-down dynamic programming.

static long fib(int n, long[] memo) {
    if (n < 2) return n;
    if (memo[n] != 0) return memo[n];
    return memo[n] = fib(n - 1, memo) + fib(n - 2, memo);        // O(n) time, O(n) space
}
// call: fib(50, new long[51])
Map<Integer, Long> cache = new HashMap<>();
long f(int n) {
    if (n < 2) return n;
    Long cached = cache.get(n);
    if (cached != null) return cached;
    long result = f(n - 1) + f(n - 2);
    cache.put(n, result);
    return result;
}
Warning

Don't call a recursive function from inside HashMap.computeIfAbsent. It modifies the map while computing and can throw ConcurrentModificationException. Use get then put, as above.

Dynamic programming is covered in depth in its own topic.

06Divide and Conquer

Divide the problem into smaller independent parts, conquer each recursively, combine the answers.

AlgorithmDivideCombineTime
Merge sortSplit array in halfMerge two sorted halvesO(n log n)
Quick sortPartition around a pivotNothing neededO(n log n) avg
Binary searchDiscard halfNothingO(log n)
Max subarray (D&C)Left / right / crossingBest of threeO(n log n)
Fast exponentiationHalve the exponentSquareO(log n)
// Maximum element by divide and conquer
static int max(int[] a, int lo, int hi) {
    if (lo == hi) return a[lo];
    int mid = lo + (hi - lo) / 2;
    return Math.max(max(a, lo, mid), max(a, mid + 1, hi));
}

07Classic Recursive Problems

Tower of Hanoi

static void hanoi(int n, char from, char to, char via) {
    if (n == 0) return;
    hanoi(n - 1, from, via, to);
    System.out.println("Move disk " + n + " from " + from + " to " + to);
    hanoi(n - 1, via, to, from);                  // 2ⁿ - 1 moves
}

Print all binary strings of length n

static void gen(int n, String cur) {
    if (cur.length() == n) { System.out.println(cur); return; }
    gen(n, cur + "0");
    gen(n, cur + "1");
}

Convert recursion to iteration

Any recursion can use an explicit Deque as a stack. Do this when depth could overflow the call stack (for example DFS on a 10⁵-node path graph).

08Backtracking

Backtracking builds a solution step by step, and when a choice leads to a dead end it undoes it (backtracks) and tries the next option. It is a systematic search of the decision tree with pruning.

The template

solve(state):
    if state is a complete solution:
        record it; return
    for each choice available from state:
        if choice is valid (prune early):
            make the choice            // choose
            solve(new state)           // explore
            undo the choice            // un-choose (backtrack)

Subsets (the power set)

static List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(nums, 0, new ArrayList<>(), res);
    return res;
}
static void backtrack(int[] nums, int start, List<Integer> cur, List<List<Integer>> res) {
    res.add(new ArrayList<>(cur));                       // every partial path is a valid subset
    for (int i = start; i < nums.length; i++) {
        cur.add(nums[i]);                                 // choose
        backtrack(nums, i + 1, cur, res);                 // explore
        cur.remove(cur.size() - 1);                       // un-choose
    }
}                                                         // O(n · 2ⁿ)
Warning

Always copy the current list (new ArrayList<>(cur)) before saving it; otherwise every saved entry points at the same list that you keep modifying.

Subsets with duplicates

Arrays.sort(nums);
// inside the loop:
if (i > start && nums[i] == nums[i - 1]) continue;       // skip duplicate choices at the same level

Permutations

static List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    permute(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}
static void permute(int[] nums, boolean[] used, List<Integer> cur, List<List<Integer>> res) {
    if (cur.size() == nums.length) { res.add(new ArrayList<>(cur)); return; }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        used[i] = true; cur.add(nums[i]);
        permute(nums, used, cur, res);
        cur.remove(cur.size() - 1); used[i] = false;
    }
}                                                         // O(n · n!)

Combination sum (reuse allowed)

static void combSum(int[] c, int start, int remain, List<Integer> cur, List<List<Integer>> res) {
    if (remain == 0) { res.add(new ArrayList<>(cur)); return; }
    for (int i = start; i < c.length; i++) {
        if (c[i] > remain) continue;                      // prune (sort first and `break` for more speed)
        cur.add(c[i]);
        combSum(c, i, remain - c[i], cur, res);           // pass i, not i+1: same number can be reused
        cur.remove(cur.size() - 1);
    }
}

Generate valid parentheses

static void gen(int open, int close, int n, StringBuilder sb, List<String> res) {
    if (sb.length() == 2 * n) { res.add(sb.toString()); return; }
    if (open < n)      { sb.append('('); gen(open + 1, close, n, sb, res); sb.setLength(sb.length() - 1); }
    if (close < open)  { sb.append(')'); gen(open, close + 1, n, sb, res); sb.setLength(sb.length() - 1); }
}                                                         // Catalan(n) results

N-Queens

Place n queens so none attack each other. Track used columns and diagonals for O(1) validity checks.

static int solveNQueens(int n) {
    return place(0, n, new boolean[n], new boolean[2 * n], new boolean[2 * n]);
}
static int place(int row, int n, boolean[] cols, boolean[] diag1, boolean[] diag2) {
    if (row == n) return 1;
    int count = 0;
    for (int c = 0; c < n; c++) {
        int d1 = row - c + n, d2 = row + c;               // "\" and "/" diagonals
        if (cols[c] || diag1[d1] || diag2[d2]) continue;  // prune
        cols[c] = diag1[d1] = diag2[d2] = true;
        count += place(row + 1, n, cols, diag1, diag2);
        cols[c] = diag1[d1] = diag2[d2] = false;
    }
    return count;
}

Word search in a grid

static boolean exist(char[][] b, String w) {
    for (int i = 0; i < b.length; i++)
        for (int j = 0; j < b[0].length; j++)
            if (dfs(b, w, i, j, 0)) return true;
    return false;
}
static boolean dfs(char[][] b, String w, int i, int j, int k) {
    if (k == w.length()) return true;
    if (i < 0 || j < 0 || i >= b.length || j >= b[0].length || b[i][j] != w.charAt(k)) return false;
    char tmp = b[i][j];
    b[i][j] = '#';                                        // mark visited
    boolean found = dfs(b, w, i + 1, j, k + 1) || dfs(b, w, i - 1, j, k + 1)
                 || dfs(b, w, i, j + 1, k + 1) || dfs(b, w, i, j - 1, k + 1);
    b[i][j] = tmp;                                        // backtrack
    return found;
}

Sudoku solver (idea)

For each empty cell try digits 1 to 9, check row/column/box validity, recurse; if no digit works, reset the cell and backtrack.

10Pruning Techniques

  • Sort first so you can break once a choice is too large
  • Skip duplicates at the same recursion level
  • Keep running totals/sets so validity checks are O(1)
  • Stop as soon as a bound proves no better solution exists (branch and bound)

12Common Mistakes

  • Forgetting the base case or making a call that doesn't shrink the problem
  • Modifying shared state and forgetting to undo it
  • Adding a reference to the working list instead of a copy
  • Exponential blow-up without memoisation
  • Using substring repeatedly (O(n) each) inside deep recursion; pass indices instead

13Quick Recap

  • Recursion = base case + smaller recursive case; cost = calls × work per call; space = depth
  • Memoise when subproblems overlap (turns O(2ⁿ) into O(n) for Fibonacci)
  • Divide and conquer splits, solves and combines (merge sort, binary search)
  • Backtracking template: choose → explore → un-choose, with early pruning
  • Copy results before storing them; sort and skip duplicates to avoid repeated answers
