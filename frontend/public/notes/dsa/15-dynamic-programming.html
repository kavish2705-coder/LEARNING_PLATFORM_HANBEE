Dynamic Programming

Solve problems with overlapping subproblems. Memoisation versus tabulation, a repeatable framework, and the core patterns: 1D, grids, knapsack, subsequences, strings and partitions, with space optimisation.

01What is Dynamic Programming?

Dynamic programming (DP) solves a problem by breaking it into overlapping subproblems, solving each once, and storing the result so it is never recomputed.

Use DP when a problem has:

  1. Overlapping subproblems: the same smaller problems repeat (unlike merge sort's independent halves)
  2. Optimal substructure: the best answer is built from best answers to subproblems

The Fibonacci story

fib(5)
├─ fib(4)
│   ├─ fib(3) ─ fib(2), fib(1)
│   └─ fib(2)           ← repeated
└─ fib(3) ─ fib(2), fib(1)   ← repeated

Plain recursion is O(2ⁿ). Remembering results makes it O(n).

02Two Implementation Styles

1. Top-down: recursion + memoisation

static long fib(int n, long[] memo) {
    if (n <= 1) return n;
    if (memo[n] != 0) return memo[n];
    return memo[n] = fib(n - 1, memo) + fib(n - 2, memo);
}

2. Bottom-up: tabulation

static long fib(int n) {
    if (n <= 1) return n;
    long[] dp = new long[n + 1];
    dp[1] = 1;
    for (int i = 2; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
    return dp[n];
}

3. Space-optimised

static long fib(int n) {
    long a = 0, b = 1;
    for (int i = 0; i < n; i++) { long t = a + b; a = b; b = t; }
    return a;                                              // O(n) time, O(1) space
}
Memoisation (top-down)Tabulation (bottom-up)
CodeNatural recursionLoops
ComputesOnly needed statesAll states
RiskStack overflow for deep recursionNone
Space optimisationHarderEasy (keep only the last rows)

03The DP Framework

  1. State: what do I need to know to describe a subproblem? (dp[i], dp[i][j], ...). Write it in words: "dp[i] = best answer using the first i items"
  2. Transition (recurrence): how does dp[state] depend on smaller states?
  3. Base cases: smallest states with known answers
  4. Order: compute states so dependencies are ready (usually increasing indexes)
  5. Answer: which cell holds the result? (dp[n], or the max over all cells)
  6. Optimise space: if dp[i] uses only dp[i-1], keep two variables or a rolling row
Tip

Start by writing the brute-force recursion. Spot the repeated calls, add a memo, then (optionally) convert it to a table.

04Pattern 1: Linear (1D) DP

Climbing stairs

Ways to climb n steps taking 1 or 2 at a time: dp[i] = dp[i-1] + dp[i-2].

static int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) { int t = a + b; a = b; b = t; }
    return b;
}

House robber (no two adjacent houses)

State: dp[i] = max money from the first i houses. Choice: skip house i or rob it.

static int rob(int[] a) {
    int prev2 = 0, prev1 = 0;
    for (int x : a) {
        int cur = Math.max(prev1, prev2 + x);                // skip, or rob this + best up to i-2
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}

Variants: circular houses (run twice, excluding the first or last), house robber on a tree.

Coin change: minimum coins

dp[a] = fewest coins for amount a; dp[a] = min(dp[a - coin] + 1).

static int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);                              // "infinity"
    dp[0] = 0;
    for (int a = 1; a <= amount; a++)
        for (int c : coins)
            if (c <= a) dp[a] = Math.min(dp[a], dp[a - c] + 1);
    return dp[amount] > amount ? -1 : dp[amount];             // O(amount × coins)
}

Coin change II: number of combinations

Loop coins outermost so each combination is counted once, regardless of order.

static int change(int amount, int[] coins) {
    int[] dp = new int[amount + 1];
    dp[0] = 1;
    for (int c : coins)
        for (int a = c; a <= amount; a++) dp[a] += dp[a - c];
    return dp[amount];
}

(Swapping the loops counts permutations instead.)

Longest increasing subsequence (LIS)

// O(n²): dp[i] = length of the LIS ending at i
static int lis(int[] a) {
    int[] dp = new int[a.length];
    Arrays.fill(dp, 1);
    int best = 1;
    for (int i = 1; i < a.length; i++) {
        for (int j = 0; j < i; j++) if (a[j] < a[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
        best = Math.max(best, dp[i]);
    }
    return best;
}

// O(n log n): tails[k] = smallest possible tail of an increasing subsequence of length k+1
static int lisFast(int[] a) {
    int[] tails = new int[a.length];
    int size = 0;
    for (int x : a) {
        int i = Arrays.binarySearch(tails, 0, size, x);
        if (i < 0) i = -(i + 1);                              // insertion point
        tails[i] = x;
        if (i == size) size++;
    }
    return size;
}

Maximum subarray (Kadane) is DP too

dp[i] = max(a[i], dp[i-1] + a[i]).

Word break

static boolean wordBreak(String s, List<String> dict) {
    Set<String> words = new HashSet<>(dict);
    boolean[] dp = new boolean[s.length() + 1];
    dp[0] = true;
    for (int i = 1; i <= s.length(); i++)
        for (int j = 0; j < i; j++)
            if (dp[j] && words.contains(s.substring(j, i))) { dp[i] = true; break; }
    return dp[s.length()];
}

Decode ways, minimum cost climbing stairs, perfect squares, jump game (DP version), maximum product subarray (track max and min), delete and earn.

05Pattern 2: Grid (2D) DP

Unique paths

Moving only right or down: dp[r][c] = dp[r-1][c] + dp[r][c-1].

static int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    for (int r = 1; r < m; r++)
        for (int c = 1; c < n; c++) dp[c] += dp[c - 1];       // rolling single row
    return dp[n - 1];
}

Minimum path sum

static int minPathSum(int[][] g) {
    int m = g.length, n = g[0].length;
    int[][] dp = new int[m][n];
    for (int r = 0; r < m; r++)
        for (int c = 0; c < n; c++) {
            if (r == 0 && c == 0) dp[r][c] = g[0][0];
            else if (r == 0) dp[r][c] = dp[r][c - 1] + g[r][c];
            else if (c == 0) dp[r][c] = dp[r - 1][c] + g[r][c];
            else dp[r][c] = Math.min(dp[r - 1][c], dp[r][c - 1]) + g[r][c];
        }
    return dp[m - 1][n - 1];
}

Maximal square

dp[r][c] = side of the largest square ending at (r, c): 1 + min(top, left, top-left) if the cell is 1.

Related: unique paths with obstacles, triangle minimum path, cherry pickup, dungeon game.

06Pattern 3: Knapsack

0/1 knapsack: each item used at most once

dp[i][w] = best value using the first i items with capacity w.

static int knapsack(int[] wt, int[] val, int cap) {
    int[] dp = new int[cap + 1];                              // 1D optimisation
    for (int i = 0; i < wt.length; i++)
        for (int w = cap; w >= wt[i]; w--)                    // iterate capacity BACKWARDS so each item is used once
            dp[w] = Math.max(dp[w], dp[w - wt[i]] + val[i]);
    return dp[cap];                                            // O(n · cap)
}

The 2D version, for clarity:

int[][] dp = new int[n + 1][cap + 1];
for (int i = 1; i <= n; i++)
    for (int w = 0; w <= cap; w++) {
        dp[i][w] = dp[i - 1][w];                              // skip item i
        if (wt[i - 1] <= w) dp[i][w] = Math.max(dp[i][w], dp[i - 1][w - wt[i - 1]] + val[i - 1]);   // take it
    }

Unbounded knapsack: unlimited copies

Same as the 1D version but iterate capacity forwards.

for (int i = 0; i < wt.length; i++)
    for (int w = wt[i]; w <= cap; w++)
        dp[w] = Math.max(dp[w], dp[w - wt[i]] + val[i]);

Subset sum and partition equal subset sum

static boolean canPartition(int[] a) {
    int sum = Arrays.stream(a).sum();
    if (sum % 2 != 0) return false;
    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;
    for (int x : a)
        for (int s = target; s >= x; s--) dp[s] |= dp[s - x];
    return dp[target];
}

07Pattern 4: Strings and Subsequences (2D)

Longest common subsequence (LCS)

dp[i][j] = LCS length of the first i chars of a and the first j chars of b.

static int lcs(String a, String b) {
    int m = a.length(), n = b.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                    ? dp[i - 1][j - 1] + 1                    // characters match: extend
                    : Math.max(dp[i - 1][j], dp[i][j - 1]);   // skip one character from either string
    return dp[m][n];                                           // O(m·n)
}

Edit distance (Levenshtein)

Minimum insert / delete / replace operations to turn a into b.

static int editDistance(String a, String b) {
    int m = a.length(), n = b.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;                // delete all
    for (int j = 0; j <= n; j++) dp[0][j] = j;                // insert all
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                    ? dp[i - 1][j - 1]
                    : 1 + Math.min(dp[i - 1][j - 1], Math.min(dp[i - 1][j], dp[i][j - 1]));   // replace, delete, insert
    return dp[m][n];
}

Longest palindromic subsequence

LPS(s) = LCS(s, reverse(s)), or dp[i][j] over the substring s[i..j].

Longest palindromic substring, palindromic substrings count

Expand around the centre (O(n²), see the Arrays and Strings topic) or fill dp[i][j] = s[i]==s[j] && dp[i+1][j-1].

08Pattern 5: Interval / Partition DP

State: dp[i][j] for the subarray [i, j]; try every split point k.

// Matrix chain multiplication idea, burst balloons, palindrome partitioning (min cuts), merge stones
for (int len = 2; len <= n; len++)
    for (int i = 0; i + len - 1 < n; i++) {
        int j = i + len - 1;
        for (int k = i; k < j; k++)
            dp[i][j] = Math.min(dp[i][j], dp[i][k] + dp[k + 1][j] + cost(i, k, j));
    }                                                          // O(n³)

09Pattern 6: DP with State Machines

Track a small "mode" per position, for example stock trading with holding / not holding / cooldown.

// Best time to buy and sell stock with cooldown
static int maxProfit(int[] p) {
    int hold = Integer.MIN_VALUE, sold = 0, rest = 0;
    for (int price : p) {
        int prevSold = sold;
        sold = hold + price;                                   // sell today
        hold = Math.max(hold, rest - price);                   // keep holding, or buy today (after a rest day)
        rest = Math.max(rest, prevSold);                       // do nothing
    }
    return Math.max(sold, rest);
}

Other examples: stock with at most k transactions (dp[t][holding]), paint house (dp[i][colour]).

11Pattern 8: DP on Trees

Compute each node's value from its children's values during a DFS (return a pair of states).

// House robber III: return {rob this node, skip this node}
static int[] robTree(TreeNode n) {
    if (n == null) return new int[]{0, 0};
    int[] l = robTree(n.left), r = robTree(n.right);
    int rob = n.val + l[1] + r[1];                             // children must be skipped
    int skip = Math.max(l[0], l[1]) + Math.max(r[0], r[1]);    // children free to be robbed or skipped
    return new int[]{rob, skip};
}

12Pattern 9: Digit DP, Probability DP, Counting DP (brief)

  • Digit DP: count numbers in a range with a property by processing digits with a tight flag
  • Counting DP: number of ways (paths, partitions), usually modulo 10⁹ + 7
  • Probability / expected value DP: knight probability, dice rolls

14Reconstructing the Answer

Store the choice taken (a parent array, or re-trace from the table) and walk back from the final state. Example: printing the LCS by walking from dp[m][n]: if characters match go diagonally and prepend the character, otherwise move toward the larger neighbour.

17Common Mistakes

  • Defining the state vaguely: write dp[i] = "…" in one sentence before coding
  • Wrong loop direction in 1D knapsack (backwards = 0/1, forwards = unbounded)
  • Not initialising base cases or "infinity" correctly (watch Integer.MAX_VALUE + 1 overflow)
  • Counting combinations vs permutations (coin loop order)
  • Off-by-one with dp[i][j] indexed by lengths versus indexes (charAt(i - 1))
  • Using plain recursion without memo on overlapping subproblems
  • Exceeding recursion depth in top-down DP with large n

18Quick Recap

  • DP = overlapping subproblems + optimal substructure; store each subproblem's answer once
  • Framework: state → transition → base case → order → answer → optimise space
  • Memoisation (top-down) vs tabulation (bottom-up); both give the same complexity
  • Core patterns: 1D (stairs, robber, coin change, LIS), grid, knapsack, subsequence/string (LCS, edit distance), interval, state machine, bitmask, tree
  • Start from brute-force recursion; find the repeated states; memoise
