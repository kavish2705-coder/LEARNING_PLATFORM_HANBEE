Stacks, Queues and Deques

LIFO and FIFO structures, their array and linked implementations, and the interview patterns built on them. Balanced brackets, monotonic stacks, min stack, queue from stacks and the sliding-window deque.

01Stack: Last In, First Out (LIFO)

Think of a stack of plates: you add and remove only at the top.

push(10) push(20) push(30)        pop() → 30
        ┌────┐                        ┌────┐
        │ 30 │ ← top                  │ 20 │ ← top
        │ 20 │                        │ 10 │
        │ 10 │                        └────┘
        └────┘
OperationMeaningTime
push(x)Add on topO(1)
pop()Remove and return the topO(1)
peek()Look at the topO(1)
isEmpty(), size()StateO(1)

Where stacks are used

  • Function call stack and recursion
  • Undo / redo in editors, browser back button
  • Expression evaluation and syntax checking (brackets)
  • DFS (iterative), backtracking
  • Monotonic-stack problems (next greater element)

02Implementing a Stack

Array-based (fixed capacity)

class ArrayStack {
    private final int[] data;
    private int top = -1;

    ArrayStack(int capacity) { data = new int[capacity]; }

    void push(int x) {
        if (top == data.length - 1) throw new IllegalStateException("Stack overflow");
        data[++top] = x;
    }
    int pop() {
        if (isEmpty()) throw new RuntimeException("Stack underflow");
        return data[top--];
    }
    int peek() {
        if (isEmpty()) throw new RuntimeException("Stack is empty");
        return data[top];
    }
    boolean isEmpty() { return top == -1; }
    int size() { return top + 1; }
}

Linked-list-based (grows dynamically)

class LinkedStack {
    private static class Node { int val; Node next; Node(int v, Node n) { val = v; next = n; } }
    private Node head;
    private int size;

    void push(int x) { head = new Node(x, head); size++; }          // add at the head: O(1)
    int pop() {
        if (head == null) throw new RuntimeException("Stack underflow");
        int v = head.val; head = head.next; size--; return v;
    }
    int peek() { return head.val; }
    boolean isEmpty() { return head == null; }
}

In practice: use ArrayDeque

Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);  stack.push(2);
stack.peek();   // 2
stack.pop();    // 2
Warning

Avoid java.util.Stack. It extends Vector (synchronised, slower) and has a confusing API. ArrayDeque is the recommended replacement. Note Deque.push adds at the front and pop removes from the front, which is exactly stack behaviour.

03Classic Stack Problems

Balanced parentheses

static boolean isValid(String s) {
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else {
            if (st.isEmpty()) return false;
            char open = st.pop();
            if ((c == ')' && open != '(') || (c == ']' && open != '[') || (c == '}' && open != '{')) return false;
        }
    }
    return st.isEmpty();                          // O(n) time, O(n) space
}

Evaluate a postfix (reverse Polish) expression

static int evalRPN(String[] tokens) {
    Deque<Integer> st = new ArrayDeque<>();
    for (String t : tokens) {
        switch (t) {
            case "+" -> st.push(st.pop() + st.pop());
            case "*" -> st.push(st.pop() * st.pop());
            case "-" -> { int b = st.pop(), a = st.pop(); st.push(a - b); }
            case "/" -> { int b = st.pop(), a = st.pop(); st.push(a / b); }
            default  -> st.push(Integer.parseInt(t));
        }
    }
    return st.pop();
}
// ["2","1","+","3","*"] → 9

Infix to postfix (Shunting-yard idea)

Scan tokens: operands go to the output; for an operator, pop operators of higher or equal precedence to the output, then push it; ( is pushed, ) pops until (. At the end pop everything.

Min stack: getMin() in O(1)

class MinStack {
    private final Deque<int[]> st = new ArrayDeque<>();       // each entry: {value, min so far}

    void push(int x) {
        int min = st.isEmpty() ? x : Math.min(x, st.peek()[1]);
        st.push(new int[]{x, min});
    }
    void pop() { st.pop(); }
    int top() { return st.peek()[0]; }
    int getMin() { return st.peek()[1]; }
}

Reverse a string / undo history

Push characters, then pop them: LIFO reverses the order.

Decode string (3[a2[c]] → accaccacc)

static String decode(String s) {
    Deque<Integer> counts = new ArrayDeque<>();
    Deque<StringBuilder> strs = new ArrayDeque<>();
    StringBuilder cur = new StringBuilder();
    int k = 0;
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) k = k * 10 + (c - '0');
        else if (c == '[') { counts.push(k); strs.push(cur); cur = new StringBuilder(); k = 0; }
        else if (c == ']') {
            StringBuilder prev = strs.pop();
            prev.append(String.valueOf(cur).repeat(counts.pop()));
            cur = prev;
        } else cur.append(c);
    }
    return cur.toString();
}

04Monotonic Stack

Keep the stack sorted (increasing or decreasing). Whenever a new element breaks the order, pop the elements it dominates, and that pop is exactly when their answer becomes known. Each element is pushed and popped at most once → O(n).

Next greater element

static int[] nextGreater(int[] a) {
    int[] res = new int[a.length];
    Arrays.fill(res, -1);
    Deque<Integer> st = new ArrayDeque<>();                  // stores indexes, values decreasing
    for (int i = 0; i < a.length; i++) {
        while (!st.isEmpty() && a[i] > a[st.peek()]) res[st.pop()] = a[i];
        st.push(i);
    }
    return res;                                               // O(n)
}
// [2,1,2,4,3] → [4,2,4,-1,-1]

Daily temperatures (days until a warmer day)

static int[] dailyTemperatures(int[] t) {
    int[] res = new int[t.length];
    Deque<Integer> st = new ArrayDeque<>();
    for (int i = 0; i < t.length; i++) {
        while (!st.isEmpty() && t[i] > t[st.peek()]) {
            int j = st.pop();
            res[j] = i - j;
        }
        st.push(i);
    }
    return res;
}

Largest rectangle in a histogram

static int largestRectangle(int[] h) {
    Deque<Integer> st = new ArrayDeque<>();                  // indexes of increasing bar heights
    int best = 0;
    for (int i = 0; i <= h.length; i++) {
        int cur = (i == h.length) ? 0 : h[i];                // sentinel 0 flushes the stack
        while (!st.isEmpty() && cur < h[st.peek()]) {
            int height = h[st.pop()];
            int left = st.isEmpty() ? -1 : st.peek();
            best = Math.max(best, height * (i - left - 1));
        }
        st.push(i);
    }
    return best;                                              // O(n)
}

Related: trapping rain water (stack version), stock span, maximal rectangle in a binary matrix, remove k digits.

05Queue: First In, First Out (FIFO)

Like a line at a ticket counter: add at the rear, remove from the front.

enqueue(1) enqueue(2) enqueue(3)

front → [ 1 | 2 | 3 ] ← rear        dequeue() → 1
OperationMeaningTime
offer(x) / add(x)Enqueue at the rearO(1)
poll() / remove()Dequeue from the frontO(1)
peek() / element()Look at the frontO(1)

Where queues are used

  • BFS on graphs and trees; level-order traversal
  • Task scheduling, print queues, message queues (Kafka, RabbitMQ)
  • Buffering streams, rate limiting, sliding-window problems

Circular array queue

Wrapping the indexes around reuses freed space.

class CircularQueue {
    private final int[] data;
    private int front = 0, size = 0;

    CircularQueue(int capacity) { data = new int[capacity]; }

    boolean offer(int x) {
        if (size == data.length) return false;                // full
        data[(front + size) % data.length] = x;
        size++;
        return true;
    }
    int poll() {
        if (size == 0) throw new RuntimeException("Queue is empty");
        int x = data[front];
        front = (front + 1) % data.length;
        size--;
        return x;
    }
    int peek() { return data[front]; }
    boolean isEmpty() { return size == 0; }
}

Linked list queue

Keep head (dequeue) and tail (enqueue) pointers so both operations are O(1).

In Java

Queue<Integer> q = new ArrayDeque<>();      // or LinkedList
q.offer(1); q.offer(2);
q.peek();    // 1
q.poll();    // 1

Prefer offer/poll/peek (return false/null on failure) over add/remove/element (throw exceptions).

06Queue and Stack from Each Other

Queue using two stacks (amortised O(1))

class MyQueue {
    private final Deque<Integer> in = new ArrayDeque<>(), out = new ArrayDeque<>();

    void push(int x) { in.push(x); }
    int pop() { shift(); return out.pop(); }
    int peek() { shift(); return out.peek(); }
    boolean empty() { return in.isEmpty() && out.isEmpty(); }

    private void shift() {                          // move only when `out` is empty
        if (out.isEmpty()) while (!in.isEmpty()) out.push(in.pop());
    }
}

Stack using one queue

class MyStack {
    private final Queue<Integer> q = new ArrayDeque<>();
    void push(int x) {
        q.offer(x);
        for (int i = 0; i < q.size() - 1; i++) q.offer(q.poll());   // rotate so the new item is at the front
    }
    int pop() { return q.poll(); }
    int top() { return q.peek(); }
}

07Deque (Double-Ended Queue)

Insert and remove at both ends in O(1). It can act as a stack or a queue.

Deque<Integer> dq = new ArrayDeque<>();
dq.addFirst(1);  dq.addLast(2);
dq.pollFirst();  dq.pollLast();
dq.peekFirst();  dq.peekLast();

Sliding window maximum (monotonic deque)

Keep indexes in the deque with their values in decreasing order. The front is always the current maximum.

static int[] maxSlidingWindow(int[] a, int k) {
    int n = a.length;
    int[] res = new int[n - k + 1];
    Deque<Integer> dq = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        if (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();          // index left the window
        while (!dq.isEmpty() && a[dq.peekLast()] <= a[i]) dq.pollLast();       // smaller values can never be the max
        dq.offerLast(i);
        if (i >= k - 1) res[i - k + 1] = a[dq.peekFirst()];
    }
    return res;                                                                 // O(n)
}

09BFS with a Queue (Preview)

static void bfs(Map<Integer, List<Integer>> g, int start) {
    Queue<Integer> q = new ArrayDeque<>();
    Set<Integer> seen = new HashSet<>();
    q.offer(start); seen.add(start);
    while (!q.isEmpty()) {
        int u = q.poll();
        for (int v : g.getOrDefault(u, List.of()))
            if (seen.add(v)) q.offer(v);                  // add returns false if already seen
    }
}

12Common Mistakes

  • Popping or peeking an empty stack/queue: always check isEmpty()
  • Using java.util.Stack/LinkedList out of habit instead of ArrayDeque
  • Storing values in a monotonic stack when you need indexes (distances, widths)
  • Forgetting that Deque.push/pop work at the front and offer/poll at the rear/front respectively
  • ArrayDeque does not allow null elements

13Quick Recap

  • Stack = LIFO (push, pop, peek in O(1)); Queue = FIFO (offer, poll, peek)
  • Use ArrayDeque for both; avoid Stack and Vector
  • Stack problems: brackets, postfix evaluation, min stack, decode string
  • Monotonic stack gives next-greater/smaller answers in O(n); monotonic deque gives sliding-window maximum
  • Queues drive BFS; two stacks can emulate a queue with amortised O(1) operations
