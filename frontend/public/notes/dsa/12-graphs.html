Graphs: Representation, BFS, DFS and Union-Find

Model relationships with graphs. Adjacency lists and matrices, BFS and DFS, grid problems, cycle detection, topological sort, bipartite checks and the disjoint-set (union-find) structure.

01What is a Graph?

A graph G = (V, E) is a set of vertices (nodes) connected by edges. Trees are special graphs (connected, no cycles). Graphs model almost any set of relationships.

Real-worldVerticesEdges
Social networkPeopleFriendships / follows
Maps and navigationIntersectionsRoads (weighted by distance)
The webPagesHyperlinks (directed)
Course planningCoursesPrerequisites (directed)
NetworksRoutersLinks (weighted by latency)
Dependency managementPackages"depends on"

03Representing a Graph

Adjacency list (the default)

int n = 5;
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());

void addEdge(int u, int v) {          // undirected
    graph.get(u).add(v);
    graph.get(v).add(u);
}
// directed: only graph.get(u).add(v)

Weighted graph:

record Edge(int to, int weight) { }
List<List<Edge>> g = new ArrayList<>();
// g.get(u).add(new Edge(v, w));

When nodes are arbitrary labels:

Map<String, List<String>> g = new HashMap<>();
g.computeIfAbsent("A", k -> new ArrayList<>()).add("B");

Adjacency matrix

boolean[][] adj = new boolean[n][n];     // or int[][] for weights
adj[u][v] = adj[v][u] = true;

Edge list

A list of (u, v, w) triples: used by Kruskal's algorithm and Bellman-Ford.

04Breadth-First Search (BFS)

Explore level by level from a start vertex using a queue. Finds the shortest path in an unweighted graph.

static void bfs(List<List<Integer>> g, int start) {
    boolean[] visited = new boolean[g.size()];
    Queue<Integer> q = new ArrayDeque<>();
    q.offer(start);
    visited[start] = true;                              // mark when ENQUEUED, not when dequeued
    while (!q.isEmpty()) {
        int u = q.poll();
        System.out.println(u);
        for (int v : g.get(u)) {
            if (!visited[v]) { visited[v] = true; q.offer(v); }
        }
    }
}                                                         // O(V + E) time, O(V) space

Shortest distance in an unweighted graph

static int[] bfsDistance(List<List<Integer>> g, int src) {
    int[] dist = new int[g.size()];
    Arrays.fill(dist, -1);
    Queue<Integer> q = new ArrayDeque<>();
    q.offer(src); dist[src] = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        for (int v : g.get(u))
            if (dist[v] == -1) { dist[v] = dist[u] + 1; q.offer(v); }
    }
    return dist;
}

05Depth-First Search (DFS)

Go as deep as possible, then backtrack, using recursion or a stack.

static void dfs(List<List<Integer>> g, int u, boolean[] visited) {
    visited[u] = true;
    for (int v : g.get(u))
        if (!visited[v]) dfs(g, v, visited);
}                                                         // O(V + E) time, O(V) stack

Iterative DFS

static void dfsIter(List<List<Integer>> g, int start) {
    boolean[] visited = new boolean[g.size()];
    Deque<Integer> st = new ArrayDeque<>();
    st.push(start);
    while (!st.isEmpty()) {
        int u = st.pop();
        if (visited[u]) continue;
        visited[u] = true;
        for (int v : g.get(u)) if (!visited[v]) st.push(v);
    }
}

BFS vs DFS

BFSDFS

06Connected Components

static int countComponents(int n, List<List<Integer>> g) {
    boolean[] visited = new boolean[n];
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (!visited[i]) { dfs(g, i, visited); count++; }
    }
    return count;
}

07Graphs on Grids

A grid is an implicit graph: each cell is a vertex, neighbours are up/down/left/right (sometimes diagonals). No need to build adjacency lists.

Number of islands

static int numIslands(char[][] grid) {
    int count = 0;
    for (int r = 0; r < grid.length; r++)
        for (int c = 0; c < grid[0].length; c++)
            if (grid[r][c] == '1') { sink(grid, r, c); count++; }
    return count;
}
static void sink(char[][] g, int r, int c) {
    if (r < 0 || c < 0 || r >= g.length || c >= g[0].length || g[r][c] != '1') return;
    g[r][c] = '0';                                         // mark visited by modifying the grid
    sink(g, r + 1, c); sink(g, r - 1, c); sink(g, r, c + 1); sink(g, r, c - 1);
}

Shortest path in a binary maze (BFS)

static int shortestPath(int[][] grid, int[] start, int[] end) {
    int rows = grid.length, cols = grid[0].length;
    int[] dr = {1, -1, 0, 0}, dc = {0, 0, 1, -1};
    boolean[][] seen = new boolean[rows][cols];
    Queue<int[]> q = new ArrayDeque<>();
    q.offer(new int[]{start[0], start[1], 0});
    seen[start[0]][start[1]] = true;
    while (!q.isEmpty()) {
        int[] cur = q.poll();
        if (cur[0] == end[0] && cur[1] == end[1]) return cur[2];
        for (int d = 0; d < 4; d++) {
            int nr = cur[0] + dr[d], nc = cur[1] + dc[d];
            if (nr >= 0 && nc >= 0 && nr < rows && nc < cols && grid[nr][nc] == 0 && !seen[nr][nc]) {
                seen[nr][nc] = true;
                q.offer(new int[]{nr, nc, cur[2] + 1});
            }
        }
    }
    return -1;
}

Multi-source BFS (rotting oranges, walls and gates, 01-matrix)

Put all sources in the queue at the start, then run BFS once: each cell gets its distance to the nearest source.

Other grid problems

Flood fill, surrounded regions, pacific-atlantic water flow, max area of island, word search (DFS + backtracking), minimum knight moves.

08Cycle Detection

Undirected graph (DFS with the parent)

static boolean hasCycleUndirected(List<List<Integer>> g) {
    boolean[] visited = new boolean[g.size()];
    for (int i = 0; i < g.size(); i++)
        if (!visited[i] && dfsCycle(g, i, -1, visited)) return true;
    return false;
}
static boolean dfsCycle(List<List<Integer>> g, int u, int parent, boolean[] visited) {
    visited[u] = true;
    for (int v : g.get(u)) {
        if (!visited[v]) { if (dfsCycle(g, v, u, visited)) return true; }
        else if (v != parent) return true;                  // reached a visited non-parent: cycle
    }
    return false;
}

Directed graph (three colours / recursion stack)

static boolean hasCycleDirected(List<List<Integer>> g) {
    int n = g.size();
    int[] state = new int[n];                               // 0 = unvisited, 1 = in current path, 2 = finished
    for (int i = 0; i < n; i++)
        if (state[i] == 0 && dfs(g, i, state)) return true;
    return false;
}
static boolean dfs(List<List<Integer>> g, int u, int[] state) {
    state[u] = 1;
    for (int v : g.get(u)) {
        if (state[v] == 1) return true;                     // back edge → cycle
        if (state[v] == 0 && dfs(g, v, state)) return true;
    }
    state[u] = 2;
    return false;
}

09Topological Sort

For a DAG, an ordering of vertices so that every edge u → v has u before v. Used for build systems, course schedules and task dependencies.

Kahn's algorithm (BFS using in-degrees)

static List<Integer> topoSort(int n, List<List<Integer>> g) {
    int[] indeg = new int[n];
    for (int u = 0; u < n; u++) for (int v : g.get(u)) indeg[v]++;

    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indeg[i] == 0) q.offer(i);

    List<Integer> order = new ArrayList<>();
    while (!q.isEmpty()) {
        int u = q.poll();
        order.add(u);
        for (int v : g.get(u)) if (--indeg[v] == 0) q.offer(v);
    }
    return order.size() == n ? order : List.of();           // shorter than n → there is a cycle
}                                                             // O(V + E)

DFS-based

Run DFS; push each vertex onto a stack after visiting all its neighbours; the reverse of finish order is a topological order.

Course schedule

"Can all courses be finished?" = "Does the prerequisite graph have no cycle?" → run Kahn's algorithm and check order.size() == n. "Course Schedule II" asks for the order itself.

10Bipartite Graph Check

A graph is bipartite if its vertices can be coloured with two colours so that no edge joins the same colour (equivalent to having no odd cycle).

static boolean isBipartite(List<List<Integer>> g) {
    int n = g.size();
    int[] color = new int[n];
    Arrays.fill(color, -1);
    for (int s = 0; s < n; s++) {
        if (color[s] != -1) continue;
        Queue<Integer> q = new ArrayDeque<>();
        q.offer(s); color[s] = 0;
        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : g.get(u)) {
                if (color[v] == -1) { color[v] = 1 - color[u]; q.offer(v); }
                else if (color[v] == color[u]) return false;
            }
        }
    }
    return true;
}

11Union-Find (Disjoint Set Union)

Tracks a collection of disjoint sets with two operations:

  • find(x): which set (representative/root) does x belong to?
  • union(x, y): merge the sets of x and y

With path compression and union by rank/size, each operation is almost O(1): O(α(n)), where α is the inverse Ackermann function (< 5 for any practical n).

class DSU {
    private final int[] parent, size;
    int components;

    DSU(int n) {
        parent = new int[n]; size = new int[n]; components = n;
        for (int i = 0; i < n; i++) { parent[i] = i; size[i] = 1; }
    }

    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);       // path compression
        return parent[x];
    }

    boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;                              // already connected (a cycle if this is an edge)
        if (size[ra] < size[rb]) { int t = ra; ra = rb; rb = t; }
        parent[rb] = ra;                                         // attach the smaller tree under the larger
        size[ra] += size[rb];
        components--;
        return true;
    }

    boolean connected(int a, int b) { return find(a) == find(b); }
}

14Common Mistakes

  • Marking visited after dequeuing in BFS (enqueues duplicates, can blow up)
  • Forgetting the visited check (infinite loop on cycles)
  • Using the parent check incorrectly in directed-graph cycle detection (use the three-state method)
  • Recursion depth overflow on large graphs: use iterative DFS or BFS
  • Not handling disconnected graphs: loop over all start vertices
  • Confusing 0-indexed and 1-indexed vertices; forgetting to add both directions for undirected edges

15Quick Recap

  • Use an adjacency list for sparse graphs (O(V + E) space); a matrix for dense ones
  • BFS (queue) = shortest path in unweighted graphs; DFS (stack/recursion) = components, cycles, topological order
  • Grids are implicit graphs; use direction arrays and multi-source BFS
  • Topological sort (Kahn or DFS) works only on DAGs; failure to order everything means a cycle
  • Union-Find with path compression and union by size gives near-constant-time connectivity queries
