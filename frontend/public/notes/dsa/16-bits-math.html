Bit Manipulation, Math and Useful Techniques

Binary tricks that replace loops, number theory for interviews (gcd, primes, modular arithmetic, fast power), overflow handling, and a toolbox of small techniques like reservoir sampling and Fisher-Yates.

03Everyday Bit Tricks

// Test the i-th bit (0-indexed from the right)
boolean isSet = (n >> i & 1) == 1;          // or (n & (1 << i)) != 0

n |= (1 << i);                              // set bit i
n &= ~(1 << i);                             // clear bit i
n ^= (1 << i);                              // toggle bit i

boolean odd = (n & 1) == 1;                 // odd / even check
int doubled = n << 1;                       // multiply by 2
int halved = n >> 1;                        // divide by 2 (floor for positives)

// Swap without a temporary (works but is not faster in practice)
a ^= b; b ^= a; a ^= b;

Check if a number is a power of two

static boolean isPowerOfTwo(int n) { return n > 0 && (n & (n - 1)) == 0; }

n & (n - 1) clears the lowest set bit: a power of two has exactly one set bit.

Count set bits (Brian Kernighan)

static int countBits(int n) {
    int count = 0;
    while (n != 0) { n &= n - 1; count++; }       // each step removes the lowest set bit
    return count;
}
// built in: Integer.bitCount(n)

Lowest set bit and related

int lowest = n & -n;                               // isolates the lowest set bit (used in Fenwick trees)
int cleared = n & (n - 1);                         // clears the lowest set bit

Counting bits for 0..n (DP)

static int[] countBitsUpTo(int n) {
    int[] res = new int[n + 1];
    for (int i = 1; i <= n; i++) res[i] = res[i >> 1] + (i & 1);
    return res;
}

04Classic Bit Problems

Single number (every other element appears twice)

static int singleNumber(int[] a) {
    int x = 0;
    for (int v : a) x ^= v;                        // pairs cancel out
    return x;                                       // O(n), O(1)
}

Missing number in 0..n

static int missingNumber(int[] a) {
    int x = a.length;
    for (int i = 0; i < a.length; i++) x ^= i ^ a[i];
    return x;
}

Two numbers appear once, the rest twice

XOR everything to get a ^ b; find any set bit (diff = x & -x); split the array by that bit and XOR each group.

Reverse bits, hamming distance

static int hammingDistance(int x, int y) { return Integer.bitCount(x ^ y); }
static int reverseBits(int n) { return Integer.reverse(n); }

Generate all subsets with a bitmask

static List<List<Integer>> subsets(int[] a) {
    int n = a.length;
    List<List<Integer>> res = new ArrayList<>();
    for (int mask = 0; mask < (1 << n); mask++) {          // 2ⁿ subsets
        List<Integer> subset = new ArrayList<>();
        for (int i = 0; i < n; i++)
            if ((mask >> i & 1) == 1) subset.add(a[i]);
        res.add(subset);
    }
    return res;
}

Maximum XOR of two numbers

Use a binary trie (see Tries) and greedily choose the opposite bit.

Warning

In Java, shift distances are taken modulo 32 for int (and 64 for long): 1 << 32 equals 1. Use 1L << k for large shifts.

06Number Theory

GCD and LCM

static int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }     // Euclid: O(log min(a, b))
static long lcm(long a, long b) { return a / gcd(a, b) * b; }            // divide first to avoid overflow

Primes: check one number in O(√n)

static boolean isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; (long) i * i <= n; i++) if (n % i == 0) return false;
    return true;
}

Sieve of Eratosthenes: all primes up to n, O(n log log n)

static boolean[] sieve(int n) {
    boolean[] isPrime = new boolean[n + 1];
    Arrays.fill(isPrime, 2, n + 1, true);
    for (int i = 2; (long) i * i <= n; i++)
        if (isPrime[i])
            for (int j = i * i; j <= n; j += i) isPrime[j] = false;      // start at i²: smaller multiples are already marked
    return isPrime;
}

Count primes below n by counting true entries.

Prime factorisation

static List<Integer> factorize(int n) {
    List<Integer> f = new ArrayList<>();
    for (int p = 2; (long) p * p <= n; p++)
        while (n % p == 0) { f.add(p); n /= p; }
    if (n > 1) f.add(n);                                   // a remaining prime factor larger than √n
    return f;
}

Divisors

Loop i from 1 to √n; each divisor i gives the pair (i, n / i).

Perfect numbers, happy numbers, Armstrong numbers, digit sums

Simple loops using % 10 and / 10; happy numbers use cycle detection (a set, or Floyd's).

07Modular Arithmetic

Problems often say "return the answer modulo 10⁹ + 7" to keep numbers within long.

static final int MOD = 1_000_000_007;

(a + b) % MOD
(a * b) % MOD                                  // use long: (long) a * b % MOD
((a - b) % MOD + MOD) % MOD                    // keep results non-negative

Fast exponentiation (binary exponentiation): O(log n)

static long power(long base, long exp, long mod) {
    long result = 1;
    base %= mod;
    while (exp > 0) {
        if ((exp & 1) == 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}

Modular inverse and division

Since MOD is prime, a⁻¹ ≡ a^(MOD-2) (mod MOD) (Fermat's little theorem), so a / b ≡ a * power(b, MOD - 2, MOD).

Combinations nCr mod p

// precompute factorials and inverse factorials once: O(n), then each nCr is O(1)
static long[] fact = new long[N + 1], inv = new long[N + 1];
static void init() {
    fact[0] = 1;
    for (int i = 1; i <= N; i++) fact[i] = fact[i - 1] * i % MOD;
    inv[N] = power(fact[N], MOD - 2, MOD);
    for (int i = N; i > 0; i--) inv[i - 1] = inv[i] * i % MOD;
}
static long nCr(int n, int r) { return r < 0 || r > n ? 0 : fact[n] * inv[r] % MOD * inv[n - r] % MOD; }

Pascal's triangle gives nCr for small n without division: C[n][r] = C[n-1][r-1] + C[n-1][r].

Reverse an integer safely

static int reverse(int x) {
    int rev = 0;
    while (x != 0) {
        int digit = x % 10;
        if (rev > Integer.MAX_VALUE / 10 || rev < Integer.MIN_VALUE / 10) return 0;   // would overflow
        rev = rev * 10 + digit;
        x /= 10;
    }
    return rev;
}

Palindrome number, power of three, ugly numbers, add digits (digital root 1 + (n-1) % 9).

10Randomised and Streaming Techniques

Fisher-Yates shuffle: unbiased, O(n)

static void shuffle(int[] a) {
    Random rnd = new Random();
    for (int i = a.length - 1; i > 0; i--) {
        int j = rnd.nextInt(i + 1);                         // 0..i inclusive
        int t = a[i]; a[i] = a[j]; a[j] = t;
    }
}

Reservoir sampling: pick k items uniformly from a stream of unknown length

static int[] reservoir(Iterator<Integer> stream, int k) {
    int[] res = new int[k];
    Random rnd = new Random();
    int i = 0;
    while (stream.hasNext()) {
        int x = stream.next();
        if (i < k) res[i] = x;
        else {
            int j = rnd.nextInt(i + 1);
            if (j < k) res[j] = x;                          // keep with probability k/(i+1)
        }
        i++;
    }
    return res;
}

Boyer-Moore voting, Floyd cycle detection, Morris traversal, Kadane

Small algorithms with O(1) space that are worth memorising by name (see earlier topics).

11Geometry Basics (Interview Level)

  • Rectangle overlap: a.left < b.right && b.left < a.right && a.top > b.bottom && b.top > a.bottom
  • Points on a line: compare slopes using the reduced fraction (dy / g, dx / g) as a hash key (avoid doubles)
  • Cross product (b - a) × (c - a): sign tells the turn direction (convex hull, point-in-polygon)
  • Closest pair: divide and conquer O(n log n); convex hull: Graham scan or Andrew's monotone chain

12Common Mistakes

  • Computing a * b in int and widening afterwards
  • Taking % of a negative number and expecting a non-negative result (((x % m) + m) % m)
  • Shifting by 32 or more bits on an int
  • Using Math.sqrt / floating point where exact integer arithmetic is needed
  • Forgetting to apply MOD at every multiplication step
  • Sieve loop with i * i overflowing int for big n (cast to long)

13Quick Recap

  • n & (n - 1) clears the lowest set bit (power-of-two test, popcount); n & -n isolates it; XOR cancels pairs
  • Bitmasks represent subsets: loop mask from 0 to 2ⁿ - 1
  • Know gcd (Euclid), the sieve, √n primality/factorisation, fast power and modular inverses
  • Guard against overflow: long, Math.addExact, (long) a * b, lo + (hi - lo) / 2
  • Handy toolbox: Fisher-Yates shuffle, reservoir sampling, Boyer-Moore voting
