Searching and Binary Search

Linear and binary search, the safe templates for boundaries, rotated arrays, and the powerful "binary search on the answer" technique.

01Linear Search

Check each element in turn. Works on any collection, sorted or not.

static int linearSearch(int[] a, int target) {
    for (int i = 0; i < a.length; i++) if (a[i] == target) return i;
    return -1;                                        // O(n) time, O(1) space
}

02Binary Search

On a sorted array, compare with the middle and discard half each step.

Find 23 in [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]

lo=0 hi=9  mid=4 (16)  → 16 < 23 → search right: lo=5
lo=5 hi=9  mid=7 (56)  → 56 > 23 → search left:  hi=6
lo=5 hi=6  mid=5 (23)  → found at index 5

Complexity: O(log n) time, O(1) space (iterative). 1,000,000 elements need at most about 20 comparisons.

Iterative

static int binarySearch(int[] a, int target) {
    int lo = 0, hi = a.length - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;                 // avoids int overflow of (lo + hi)
        if (a[mid] == target) return mid;
        if (a[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

Recursive

static int bs(int[] a, int target, int lo, int hi) {
    if (lo > hi) return -1;
    int mid = lo + (hi - lo) / 2;
    if (a[mid] == target) return mid;
    return a[mid] < target ? bs(a, target, mid + 1, hi) : bs(a, target, lo, mid - 1);
}
Warning

(lo + hi) / 2 can overflow when lo + hi > Integer.MAX_VALUE. Always write lo + (hi - lo) / 2.

Requirements

  • Data must be sorted (or the condition must be monotonic: false…false true…true)
  • Needs random access (arrays, ArrayList); not efficient on linked lists

03The Boundary Templates

Many bugs come from off-by-one errors. Learn one template for finding a boundary and reuse it.

Lower bound: first index where a[i] >= target

static int lowerBound(int[] a, int target) {
    int lo = 0, hi = a.length;                        // hi is exclusive: answer may be a.length
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}

Upper bound: first index where a[i] > target

static int upperBound(int[] a, int target) {
    int lo = 0, hi = a.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] <= target) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}

static int[] searchRange(int[] a, int x) {            // first and last position
    int first = lowerBound(a, x);
    if (first == a.length || a[first] != x) return new int[]{-1, -1};
    return new int[]{first, upperBound(a, x) - 1};
}

The general "first true" template

// Find the smallest value in [lo, hi] for which isGood(value) is true; isGood must be monotonic
int lo = LOW, hi = HIGH;
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (isGood(mid)) hi = mid;
    else lo = mid + 1;
}
return lo;

04Java Library Support

int i = Arrays.binarySearch(sortedArray, key);        // index if found, otherwise -(insertionPoint) - 1
int j = Collections.binarySearch(sortedList, key);

if (i < 0) { int insertAt = -i - 1; }

With duplicates the returned index is unspecified; write your own bound functions for first/last.

For sorted dynamic data, TreeSet/TreeMap provide floor, ceiling, lower, higher in O(log n).

05Classic Binary Search Problems

Search in a rotated sorted array

One half is always sorted; check whether the target lies in the sorted half.

static int searchRotated(int[] a, int target) {
    int lo = 0, hi = a.length - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] == target) return mid;
        if (a[lo] <= a[mid]) {                         // left half sorted
            if (a[lo] <= target && target < a[mid]) hi = mid - 1;
            else lo = mid + 1;
        } else {                                       // right half sorted
            if (a[mid] < target && target <= a[hi]) lo = mid + 1;
            else hi = mid - 1;
        }
    }
    return -1;
}

With duplicates the sorted half cannot always be identified (a[lo] == a[mid] == a[hi]); shrink both ends and the worst case becomes O(n).

Find the minimum in a rotated sorted array

static int findMin(int[] a) {
    int lo = 0, hi = a.length - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] > a[hi]) lo = mid + 1;              // minimum is to the right
        else hi = mid;
    }
    return a[lo];
}

Find a peak element: O(log n)

static int findPeak(int[] a) {
    int lo = 0, hi = a.length - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < a[mid + 1]) lo = mid + 1;          // a peak exists on the rising side
        else hi = mid;
    }
    return lo;
}

Integer square root

static int mySqrt(int x) {
    int lo = 0, hi = x;
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;               // upper mid so the loop terminates
        if ((long) mid * mid <= x) lo = mid; else hi = mid - 1;
    }
    return lo;
}

Search a 2D sorted matrix (each row sorted, first of each row > last of previous)

Treat it as one sorted array of rows * cols elements: value = m[mid / cols][mid % cols].

Single element in a sorted array of pairs, first bad version, find the smallest letter greater than target: all boundary searches.

06Binary Search on the Answer

When the question asks for the minimum (or maximum) value of something and you can test a candidate quickly, binary search the range of possible answers, not the array.

Recipe

  1. Define the answer range [lo, hi]
  2. Write feasible(x): "can we achieve the goal with value x?" (must be monotonic)
  3. Binary search for the smallest feasible x (or largest)

Koko eating bananas (minimum speed)

static int minEatingSpeed(int[] piles, int h) {
    int lo = 1, hi = Arrays.stream(piles).max().getAsInt();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canFinish(piles, mid, h)) hi = mid; else lo = mid + 1;
    }
    return lo;
}
static boolean canFinish(int[] piles, int speed, int h) {
    long hours = 0;
    for (int p : piles) hours += (p + speed - 1) / speed;           // ceil(p / speed)
    return hours <= h;
}

Capacity to ship packages within D days

static int shipWithinDays(int[] w, int days) {
    int lo = Arrays.stream(w).max().getAsInt();                     // must fit the heaviest package
    int hi = Arrays.stream(w).sum();                                // everything in one day
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (daysNeeded(w, mid) <= days) hi = mid; else lo = mid + 1;
    }
    return lo;
}
static int daysNeeded(int[] w, int cap) {
    int days = 1, load = 0;
    for (int x : w) {
        if (load + x > cap) { days++; load = 0; }
        load += x;
    }
    return days;
}

Floating-point binary search

double lo = 0, hi = x;
for (int i = 0; i < 100; i++) {                    // fixed iterations instead of comparing to epsilon
    double mid = (lo + hi) / 2;
    if (mid * mid <= x) lo = mid; else hi = mid;
}

08Choosing a Search Method

SituationUse
Unsorted, one-off searchLinear search
Sorted array, many lookupsBinary search
Many lookups on unsorted dataBuild a HashSet/HashMap first

09Common Mistakes

  • (lo + hi) / 2 overflow
  • Infinite loops from lo = mid with floor division (use upper mid when moving lo = mid)
  • Mixing lo <= hi templates with lo < hi templates
  • Forgetting that the data must be sorted / the condition monotonic
  • Not checking i < n before reading a[i] after a bound search
  • Using Arrays.binarySearch on arrays with duplicates and assuming it returns the first match

10Quick Recap

  • Linear search is O(n); binary search on sorted data is O(log n)
  • Use mid = lo + (hi - lo) / 2; learn the lower bound / upper bound templates for first/last/insert positions
  • For rotated arrays one half is always sorted
  • Binary search on the answer: define a monotonic feasible(x) and search the value range
  • TreeMap/TreeSet offer floor/ceiling queries on dynamic data
