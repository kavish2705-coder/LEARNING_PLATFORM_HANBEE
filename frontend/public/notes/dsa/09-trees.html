Trees and Binary Trees

Tree terminology, binary tree traversals (recursive and iterative), level-order BFS, and the recursive patterns behind height, diameter, paths, lowest common ancestor and tree construction.

01What is a Tree?

A tree is a hierarchical structure of nodes connected by edges, with no cycles. One node is the root; every other node has exactly one parent.

            1            ← root (level 0)
          /   \
         2     3         ← children of 1 (level 1)
        / \     \
       4   5     6       ← 4, 5, 6 are leaves (no children)

Terminology

TermMeaning
RootTopmost node (no parent)
LeafNode with no children
Parent / child / siblingDirect relationships
Ancestor / descendantAnywhere above / below on a path
Depth of a nodeEdges from the root to the node
Height of a nodeEdges on the longest path down to a leaf
Height of a treeHeight of the root
LevelAll nodes at the same depth
SubtreeA node together with all its descendants
DegreeNumber of children of a node

A tree with n nodes has exactly n - 1 edges.

Where trees are used

File systems, the HTML DOM, organisation charts, database indexes (B-trees), compilers (syntax trees), TreeMap/TreeSet, decision trees, routing tables, autocomplete (tries).

02Binary Tree

Each node has at most two children: left and right.

class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

TreeNode root = new TreeNode(1);
root.left = new TreeNode(2);
root.right = new TreeNode(3);
root.left.left = new TreeNode(4);

Types of binary trees

TypeDefinition
FullEvery node has 0 or 2 children
CompleteAll levels full except possibly the last, filled left to right (used by heaps)
PerfectAll internal nodes have 2 children and all leaves are at the same level (2^(h+1) - 1 nodes)
BalancedHeights of left and right subtrees differ by at most 1 at every node
Degenerate (skewed)Each node has one child: behaves like a linked list, O(n) height

Useful facts

  • A binary tree of height h has at most 2^(h+1) - 1 nodes
  • A balanced tree with n nodes has height O(log n)
  • Array representation (for complete trees): node i has children 2i+1, 2i+2 and parent (i-1)/2

03Tree Traversals

Depth-first (DFS) traversals

OrderVisit sequenceTypical use
PreorderRoot, Left, RightCopy a tree, serialise
InorderLeft, Root, RightSorted order for a BST
PostorderLeft, Right, RootDelete a tree, compute subtree values
static void preorder(TreeNode n, List<Integer> out) {
    if (n == null) return;
    out.add(n.val);
    preorder(n.left, out);
    preorder(n.right, out);
}
static void inorder(TreeNode n, List<Integer> out) {
    if (n == null) return;
    inorder(n.left, out);
    out.add(n.val);
    inorder(n.right, out);
}
static void postorder(TreeNode n, List<Integer> out) {
    if (n == null) return;
    postorder(n.left, out);
    postorder(n.right, out);
    out.add(n.val);
}

For the tree above: preorder 1 2 4 5 3 6, inorder 4 2 5 1 3 6, postorder 4 5 2 6 3 1.

All three are O(n) time and O(h) space (recursion stack, h = height).

Iterative inorder (explicit stack)

static List<Integer> inorderIter(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> st = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !st.isEmpty()) {
        while (cur != null) { st.push(cur); cur = cur.left; }   // go as far left as possible
        cur = st.pop();
        res.add(cur.val);
        cur = cur.right;
    }
    return res;
}

Iterative preorder

static List<Integer> preorderIter(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> st = new ArrayDeque<>();
    st.push(root);
    while (!st.isEmpty()) {
        TreeNode n = st.pop();
        res.add(n.val);
        if (n.right != null) st.push(n.right);                   // push right first so left is processed first
        if (n.left != null) st.push(n.left);
    }
    return res;
}
Tip

Iterative postorder = reverse of a modified preorder (Root, Right, Left).

Morris traversal

Inorder in O(n) time and O(1) space by temporarily threading links. Worth knowing by name.

Breadth-first (level-order) traversal

static List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();                                      // number of nodes on this level
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode n = q.poll();
            level.add(n.val);
            if (n.left != null) q.offer(n.left);
            if (n.right != null) q.offer(n.right);
        }
        res.add(level);
    }
    return res;                                                   // O(n) time, O(width) space
}

Level-order variations

ProblemTweak
Zigzag level orderReverse every other level (or use a deque)
Right side viewTake the last node of each level
Average / max per levelAggregate inside the level loop
Minimum depthReturn at the first leaf found
Bottom-up level orderReverse the result
Connect next pointersLink nodes within a level

04Recursive Tree Thinking

Most tree problems follow one template: solve for the left, solve for the right, combine at the root.

f(node):
    if node is null: return base value
    left  = f(node.left)
    right = f(node.right)
    return combine(node.val, left, right)

Height / maximum depth

static int height(TreeNode n) {
    if (n == null) return 0;
    return 1 + Math.max(height(n.left), height(n.right));
}

Count nodes, sum of values, count leaves

static int count(TreeNode n) { return n == null ? 0 : 1 + count(n.left) + count(n.right); }
static int sum(TreeNode n)   { return n == null ? 0 : n.val + sum(n.left) + sum(n.right); }
static int leaves(TreeNode n) {
    if (n == null) return 0;
    if (n.left == null && n.right == null) return 1;
    return leaves(n.left) + leaves(n.right);
}

Invert (mirror) a tree

static TreeNode invert(TreeNode n) {
    if (n == null) return null;
    TreeNode left = invert(n.left), right = invert(n.right);
    n.left = right; n.right = left;
    return n;
}

Same tree and symmetric tree

static boolean same(TreeNode a, TreeNode b) {
    if (a == null && b == null) return true;
    if (a == null || b == null || a.val != b.val) return false;
    return same(a.left, b.left) && same(a.right, b.right);
}
static boolean isSymmetric(TreeNode root) { return root == null || mirror(root.left, root.right); }
static boolean mirror(TreeNode a, TreeNode b) {
    if (a == null && b == null) return true;
    if (a == null || b == null || a.val != b.val) return false;
    return mirror(a.left, b.right) && mirror(a.right, b.left);
}

Balanced tree check in O(n)

static boolean isBalanced(TreeNode root) { return check(root) != -1; }
static int check(TreeNode n) {                                    // returns height, or -1 if unbalanced
    if (n == null) return 0;
    int l = check(n.left); if (l == -1) return -1;
    int r = check(n.right); if (r == -1) return -1;
    return Math.abs(l - r) > 1 ? -1 : 1 + Math.max(l, r);
}

Diameter of a tree (longest path between any two nodes)

static int diameter;
static int depth(TreeNode n) {
    if (n == null) return 0;
    int l = depth(n.left), r = depth(n.right);
    diameter = Math.max(diameter, l + r);                         // path through this node
    return 1 + Math.max(l, r);
}

Path sum (root-to-leaf)

static boolean hasPathSum(TreeNode n, int target) {
    if (n == null) return false;
    if (n.left == null && n.right == null) return n.val == target;
    return hasPathSum(n.left, target - n.val) || hasPathSum(n.right, target - n.val);
}

All root-to-leaf paths (backtracking)

static void paths(TreeNode n, List<Integer> cur, List<List<Integer>> res) {
    if (n == null) return;
    cur.add(n.val);
    if (n.left == null && n.right == null) res.add(new ArrayList<>(cur));
    else { paths(n.left, cur, res); paths(n.right, cur, res); }
    cur.remove(cur.size() - 1);                                    // backtrack
}

Maximum path sum (any node to any node)

static int best = Integer.MIN_VALUE;
static int gain(TreeNode n) {
    if (n == null) return 0;
    int l = Math.max(0, gain(n.left)), r = Math.max(0, gain(n.right));   // ignore negative branches
    best = Math.max(best, n.val + l + r);                                 // path bending at this node
    return n.val + Math.max(l, r);                                        // path continuing upward
}

05Lowest Common Ancestor (LCA)

The deepest node that has both p and q as descendants.

static TreeNode lca(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lca(root.left, p, q);
    TreeNode right = lca(root.right, p, q);
    if (left != null && right != null) return root;                // p and q are on different sides
    return left != null ? left : right;
}                                                                   // O(n)

(For a BST the LCA is found in O(h) using the ordering; see the BST topic.)

06Constructing a Tree

From preorder and inorder

The first preorder element is the root; its position in inorder splits left and right subtrees.

static TreeNode build(int[] pre, int[] in) {
    Map<Integer, Integer> idx = new HashMap<>();
    for (int i = 0; i < in.length; i++) idx.put(in[i], i);
    return build(pre, 0, pre.length - 1, 0, in.length - 1, idx);
}
static TreeNode build(int[] pre, int ps, int pe, int is, int ie, Map<Integer, Integer> idx) {
    if (ps > pe) return null;
    TreeNode root = new TreeNode(pre[ps]);
    int mid = idx.get(root.val);
    int leftSize = mid - is;
    root.left  = build(pre, ps + 1, ps + leftSize, is, mid - 1, idx);
    root.right = build(pre, ps + leftSize + 1, pe, mid + 1, ie, idx);
    return root;                                                    // O(n)
}

Preorder or postorder alone cannot determine a tree; two traversals including inorder can.

Serialize and deserialize (preorder with null markers)

static String serialize(TreeNode n) {
    if (n == null) return "#";
    return n.val + "," + serialize(n.left) + "," + serialize(n.right);
}
static TreeNode deserialize(String data) {
    Deque<String> q = new ArrayDeque<>(Arrays.asList(data.split(",")));
    return build(q);
}
static TreeNode build(Deque<String> q) {
    String s = q.poll();
    if (s.equals("#")) return null;
    TreeNode n = new TreeNode(Integer.parseInt(s));
    n.left = build(q);
    n.right = build(q);
    return n;
}

08Passing State: Down vs Up

  • Down (parameters): carry information from ancestors, such as the current path or the allowed range
  • Up (return values): return information about the subtree, such as height or validity
  • Global/field variable: track a best answer when the path can bend (diameter, max path sum)

09N-ary Trees

class Node { int val; List<Node> children = new ArrayList<>(); }

static void dfs(Node n) {
    if (n == null) return;
    for (Node c : n.children) dfs(c);
}

Level-order works the same way with a queue.

10Complexity Cheat Sheet

OperationTimeSpace
Any traversalO(n)O(h) DFS, O(w) BFS
Height, count, sumO(n)O(h)
LCA (general tree)O(n)O(h)
Build from two traversalsO(n)O(n)

h is between log n (balanced) and n (skewed). Recursion on a skewed tree of 100,000 nodes can overflow the stack: use an iterative traversal.

11Common Mistakes

  • Missing the null base case
  • Confusing height in nodes (null = 0) with height in edges (null = -1)
  • Forgetting to backtrack (remove) when collecting paths
  • Storing global variables as static across multiple test cases without resetting them
  • Assuming the tree is a BST when it is only a binary tree
  • Comparing nodes by val when you need reference identity (and vice versa)

12Quick Recap

  • Tree = root + subtrees; binary tree = at most two children; height is O(log n) when balanced
  • DFS: preorder/inorder/postorder (O(n), stack O(h)); BFS: level order with a queue
  • Template: recurse left, recurse right, combine; return info up, pass constraints down
  • Master these: height, diameter, balanced, symmetric, path sum, LCA, build from preorder + inorder, serialise
  • Convert to iterative traversal when the tree may be deep
