Linked Lists

Build singly and doubly linked lists from scratch, then solve the classic interview problems. Reversal, fast and slow pointers, cycle detection, merging, and an LRU cache.

01What is a Linked List?

A linked list is a chain of nodes. Each node stores a value and a reference to the next node. Nodes live anywhere in memory; the links connect them.

In practice ArrayList beats LinkedList for most uses because arrays are cache-friendly. Linked lists matter for understanding pointers, interviews, and structures built on them (queues, LRU caches, adjacency lists).

03Singly Linked List in Java

class Node {
    int val;
    Node next;
    Node(int val) { this.val = val; }
}

class SinglyLinkedList {
    private Node head;
    private int size;

    void addFirst(int v) {                       // O(1)
        Node n = new Node(v);
        n.next = head;
        head = n;
        size++;
    }

    void addLast(int v) {                        // O(n); O(1) if you also keep a tail pointer
        Node n = new Node(v);
        if (head == null) { head = n; size++; return; }
        Node cur = head;
        while (cur.next != null) cur = cur.next;
        cur.next = n;
        size++;
    }

    void insertAt(int index, int v) {            // O(n)
        if (index < 0 || index > size) throw new IndexOutOfBoundsException();
        if (index == 0) { addFirst(v); return; }
        Node prev = head;
        for (int i = 0; i < index - 1; i++) prev = prev.next;
        Node n = new Node(v);
        n.next = prev.next;
        prev.next = n;
        size++;
    }

    boolean deleteValue(int v) {                 // O(n)
        if (head == null) return false;
        if (head.val == v) { head = head.next; size--; return true; }
        Node cur = head;
        while (cur.next != null && cur.next.val != v) cur = cur.next;
        if (cur.next == null) return false;
        cur.next = cur.next.next;
        size--;
        return true;
    }

    boolean contains(int v) {
        for (Node cur = head; cur != null; cur = cur.next) if (cur.val == v) return true;
        return false;
    }

    void print() {
        for (Node cur = head; cur != null; cur = cur.next) System.out.print(cur.val + " -> ");
        System.out.println("null");
    }
}

04Techniques You Must Know

1. The dummy (sentinel) node

A fake node before the head removes special cases when the head itself can change.

static Node removeAll(Node head, int target) {
    Node dummy = new Node(0);
    dummy.next = head;
    Node cur = dummy;
    while (cur.next != null) {
        if (cur.next.val == target) cur.next = cur.next.next;
        else cur = cur.next;
    }
    return dummy.next;
}

2. Fast and slow pointers (Floyd's tortoise and hare)

Move slow one step and fast two steps. Useful for the middle, cycles and the k-th from the end.

static Node middle(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;                                  // second middle for even length
}

3. Reverse by relinking pointers

Rewire next pointers instead of moving data.

05Reverse a Linked List

Iterative: O(n) time, O(1) space

static Node reverse(Node head) {
    Node prev = null, cur = head;
    while (cur != null) {
        Node next = cur.next;     // save
        cur.next = prev;          // flip
        prev = cur;               // advance
        cur = next;
    }
    return prev;
}

Recursive: O(n) time, O(n) stack

static Node reverseRec(Node head) {
    if (head == null || head.next == null) return head;
    Node newHead = reverseRec(head.next);
    head.next.next = head;        // make the next node point back to me
    head.next = null;
    return newHead;
}

Reverse a sublist from position left to right

static Node reverseBetween(Node head, int left, int right) {
    Node dummy = new Node(0);
    dummy.next = head;
    Node prev = dummy;
    for (int i = 1; i < left; i++) prev = prev.next;
    Node cur = prev.next;
    for (int i = 0; i < right - left; i++) {       // pull the next node to the front of the section
        Node move = cur.next;
        cur.next = move.next;
        move.next = prev.next;
        prev.next = move;
    }
    return dummy.next;
}

06Detect a Cycle

static boolean hasCycle(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;            // they meet only if there is a loop
    }
    return false;                                  // O(n) time, O(1) space
}

Find where the cycle starts

static Node cycleStart(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            slow = head;                           // reset one pointer to the head
            while (slow != fast) { slow = slow.next; fast = fast.next; }   // move both one step
            return slow;                           // they meet at the cycle start
        }
    }
    return null;
}

Why it works: the distance from the head to the cycle start equals the distance from the meeting point to the cycle start (going around the loop).

07Merge Two Sorted Lists

static Node mergeTwo(Node a, Node b) {
    Node dummy = new Node(0), tail = dummy;
    while (a != null && b != null) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else                { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = (a != null) ? a : b;
    return dummy.next;                             // O(m + n), O(1) extra space
}

Merge sort on a linked list: O(n log n), O(log n) stack

static Node sortList(Node head) {
    if (head == null || head.next == null) return head;
    Node slow = head, fast = head.next;            // find the middle
    while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; }
    Node right = slow.next;
    slow.next = null;                              // cut the list in two
    return mergeTwo(sortList(head), sortList(right));
}

08Remove the N-th Node from the End

One pass with a gap of n between two pointers.

static Node removeNthFromEnd(Node head, int n) {
    Node dummy = new Node(0);
    dummy.next = head;
    Node fast = dummy, slow = dummy;
    for (int i = 0; i < n; i++) fast = fast.next;          // create the gap
    while (fast.next != null) { fast = fast.next; slow = slow.next; }
    slow.next = slow.next.next;
    return dummy.next;
}

09Palindrome Linked List: O(n) time, O(1) space

static boolean isPalindrome(Node head) {
    if (head == null || head.next == null) return true;
    Node slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) { slow = slow.next; fast = fast.next.next; }
    Node second = reverse(slow.next);              // reverse the second half
    Node p1 = head, p2 = second;
    boolean ok = true;
    while (p2 != null) {
        if (p1.val != p2.val) { ok = false; break; }
        p1 = p1.next; p2 = p2.next;
    }
    slow.next = reverse(second);                   // restore the list
    return ok;
}

10Intersection of Two Lists

static Node intersection(Node a, Node b) {
    Node p = a, q = b;
    while (p != q) {                               // after switching heads both travel the same total length
        p = (p == null) ? b : p.next;
        q = (q == null) ? a : q.next;
    }
    return p;                                      // intersection node or null
}

12Doubly Linked List

class DNode {
    int val;
    DNode prev, next;
    DNode(int val) { this.val = val; }
}

class DoublyLinkedList {
    private final DNode head = new DNode(0), tail = new DNode(0);    // sentinels
    DoublyLinkedList() { head.next = tail; tail.prev = head; }

    void addFirst(DNode n) {                       // O(1)
        n.next = head.next; n.prev = head;
        head.next.prev = n; head.next = n;
    }
    void remove(DNode n) {                         // O(1): we already hold the node
        n.prev.next = n.next;
        n.next.prev = n.prev;
    }
    DNode removeLast() {
        DNode last = tail.prev;
        if (last == head) return null;
        remove(last);
        return last;
    }
}

Advantage: deletion of a given node and backward traversal in O(1) / O(n); cost: an extra pointer per node.

13LRU Cache: HashMap + Doubly Linked List

Least Recently Used cache: get and put in O(1), evicting the least recently used entry when full.

class LRUCache {
    private static class Node {
        int key, val;
        Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }

    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0), tail = new Node(0, 0);   // head = most recent, tail = least recent

    LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail; tail.prev = head;
    }

    int get(int key) {
        Node n = map.get(key);
        if (n == null) return -1;
        remove(n); addFront(n);                     // mark as recently used
        return n.val;
    }

    void put(int key, int value) {
        Node n = map.get(key);
        if (n != null) { n.val = value; remove(n); addFront(n); return; }
        if (map.size() == capacity) {
            Node lru = tail.prev;
            remove(lru);
            map.remove(lru.key);
        }
        n = new Node(key, value);
        map.put(key, n);
        addFront(n);
    }

    private void remove(Node n) { n.prev.next = n.next; n.next.prev = n.prev; }
    private void addFront(Node n) { n.next = head.next; n.prev = head; head.next.prev = n; head.next = n; }
}

The shortcut in Java:

class LRU<K, V> extends LinkedHashMap<K, V> {
    private final int capacity;
    LRU(int capacity) { super(capacity, 0.75f, true); this.capacity = capacity; }   // true = access order
    @Override protected boolean removeEldestEntry(Map.Entry<K, V> e) { return size() > capacity; }
}

LinkedList<Integer> list = new LinkedList<>();     // doubly linked, also implements Deque
list.addFirst(1);  list.addLast(2);  list.removeFirst();  list.peekLast();

Prefer ArrayDeque for stacks and queues, and ArrayList for lists.

15Common Pitfalls

  • Null pointer errors: check node != null and node.next != null before dereferencing
  • Losing the rest of the list: save next before changing pointers
  • Forgetting to update head/tail when the first or last node changes
  • Off-by-one on "k-th from end"; use a dummy node to avoid special cases
  • Infinite loops in cyclic lists; use fast/slow pointers
  • Draw boxes and arrows on paper: pointer problems are much easier to see than to imagine

16Quick Recap

  • A linked list gives O(1) insert/delete at a known node but O(n) access
  • Use a dummy node to simplify head edge cases; use fast/slow pointers for middle, cycles and k-th from end
  • Reverse by relinking: save next, flip, advance (3 pointers, O(1) space)
  • Detect a cycle with Floyd's algorithm; find its start by resetting one pointer to the head
  • LRU cache = HashMap + doubly linked list for O(1) get/put
