Greedy Algorithms

Make the locally best choice at each step. When greedy works and when it fails, the exchange argument, and the classic problems: intervals, jump game, gas station, Huffman coding and more.

01What is a Greedy Algorithm?

A greedy algorithm builds a solution by repeatedly choosing the best-looking option right now, and never reconsiders earlier choices.

Greedy:    choose the locally best step → commit → repeat

It is fast and simple (usually O(n log n) from sorting, or O(n)), but it only gives the optimal answer when the problem has the right structure.

02When Does Greedy Work?

Two properties must hold:

  1. Greedy-choice property: a globally optimal solution can be reached by making a locally optimal choice first
  2. Optimal substructure: after the choice, what remains is a smaller instance of the same problem

Proof technique: the exchange argument

Take any optimal solution that differs from the greedy one. Show you can swap its first different choice for the greedy choice without making it worse. Repeating this transforms the optimal solution into the greedy one, so greedy is optimal.

Greedy vs dynamic programming

GreedyDynamic programming
DecisionsOne local choice, never revisitedConsiders all choices, remembers sub-results
SpeedFasterSlower
CorrectnessOnly for special problemsWorks whenever subproblems overlap
ExampleFractional knapsack0/1 knapsack
Tip

If you suspect greedy, look for a counter-example with small inputs. If you cannot find one, try the exchange argument. If you can, switch to DP.

03When Greedy Fails: Coin Change

With coins {1, 3, 4} and amount 6, greedy takes 4 + 1 + 1 (3 coins), but the optimum is 3 + 3 (2 coins). For canonical systems like {1, 5, 10, 25} greedy works. For arbitrary coins use DP.

04Classic Greedy Problems

1. Activity selection / maximum non-overlapping intervals

Always pick the activity that finishes earliest.

static int maxActivities(int[][] acts) {                   // {start, end}
    Arrays.sort(acts, (a, b) -> Integer.compare(a[1], b[1]));
    int count = 0, lastEnd = Integer.MIN_VALUE;
    for (int[] a : acts) {
        if (a[0] >= lastEnd) { count++; lastEnd = a[1]; }
    }
    return count;                                            // O(n log n)
}

Why: finishing earliest leaves the most room for the rest (exchange argument).

2. Minimum intervals to remove so none overlap

static int eraseOverlapIntervals(int[][] iv) {
    return iv.length - maxActivities(iv);                     // keep the maximum set, erase the rest
}

3. Merge intervals / insert interval

Sort by start, then sweep and extend the current interval (see the Sorting topic).

4. Minimum number of arrows to burst balloons

Sort by end; shoot at the end of the first balloon; skip all balloons it bursts.

static int findMinArrowShots(int[][] pts) {
    Arrays.sort(pts, (a, b) -> Integer.compare(a[1], b[1]));  // compare, don't subtract: values can be extreme
    int arrows = 0;
    long end = Long.MIN_VALUE;
    for (int[] p : pts) {
        if (p[0] > end) { arrows++; end = p[1]; }
    }
    return arrows;
}

5. Fractional knapsack

Take items in decreasing value/weight ratio; take a fraction of the last item.

static double fractionalKnapsack(int[] w, int[] v, int cap) {
    Integer[] idx = new Integer[w.length];
    for (int i = 0; i < idx.length; i++) idx[i] = i;
    Arrays.sort(idx, (a, b) -> Double.compare((double) v[b] / w[b], (double) v[a] / w[a]));
    double value = 0;
    for (int i : idx) {
        if (cap == 0) break;
        int take = Math.min(w[i], cap);
        value += (double) v[i] * take / w[i];
        cap -= take;
    }
    return value;
}

(The 0/1 knapsack cannot be solved greedily: it needs DP.)

6. Jump game

Can you reach the last index? Track the farthest reachable index.

static boolean canJump(int[] a) {
    int far = 0;
    for (int i = 0; i < a.length; i++) {
        if (i > far) return false;                            // stuck before reaching i
        far = Math.max(far, i + a[i]);
    }
    return true;
}

Jump game II: minimum number of jumps

static int jump(int[] a) {
    int jumps = 0, curEnd = 0, far = 0;
    for (int i = 0; i < a.length - 1; i++) {
        far = Math.max(far, i + a[i]);
        if (i == curEnd) { jumps++; curEnd = far; }           // must jump: extend to the farthest reachable
    }
    return jumps;                                              // O(n), a BFS in disguise
}

7. Gas station (circular tour)

static int canCompleteCircuit(int[] gas, int[] cost) {
    int total = 0, tank = 0, start = 0;
    for (int i = 0; i < gas.length; i++) {
        int diff = gas[i] - cost[i];
        total += diff; tank += diff;
        if (tank < 0) { start = i + 1; tank = 0; }              // can't start at or before i
    }
    return total >= 0 ? start : -1;                             // O(n)
}

8. Assign cookies / two-pointer greedy

Sort both arrays; give each child the smallest cookie that satisfies them.

static int findContentChildren(int[] greed, int[] cookies) {
    Arrays.sort(greed); Arrays.sort(cookies);
    int child = 0;
    for (int cookie : cookies)
        if (child < greed.length && cookie >= greed[child]) child++;
    return child;
}

9. Task scheduler / minimum idle time

Count frequencies; the most frequent task forces a frame structure:

static int leastInterval(char[] tasks, int n) {
    int[] f = new int[26];
    for (char c : tasks) f[c - 'A']++;
    int max = Arrays.stream(f).max().getAsInt();
    int maxCount = (int) Arrays.stream(f).filter(x -> x == max).count();
    return Math.max(tasks.length, (max - 1) * (n + 1) + maxCount);
}

10. Best time to buy and sell stock II

Collect every upward price move.

static int maxProfit(int[] p) {
    int profit = 0;
    for (int i = 1; i < p.length; i++) if (p[i] > p[i - 1]) profit += p[i] - p[i - 1];
    return profit;
}

Partition labels

static List<Integer> partitionLabels(String s) {
    int[] last = new int[26];
    for (int i = 0; i < s.length(); i++) last[s.charAt(i) - 'a'] = i;
    List<Integer> res = new ArrayList<>();
    int start = 0, end = 0;
    for (int i = 0; i < s.length(); i++) {
        end = Math.max(end, last[s.charAt(i) - 'a']);
        if (i == end) { res.add(end - start + 1); start = i + 1; }
    }
    return res;
}

05Huffman Coding

Compress data by giving shorter codes to more frequent symbols. Repeatedly merge the two least frequent nodes using a min-heap; the resulting binary tree gives a prefix-free code (no code is a prefix of another).

static class HNode implements Comparable<HNode> {
    char ch; int freq; HNode left, right;
    HNode(char c, int f) { ch = c; freq = f; }
    HNode(HNode l, HNode r) { freq = l.freq + r.freq; left = l; right = r; }
    public int compareTo(HNode o) { return Integer.compare(freq, o.freq); }
}

static Map<Character, String> huffman(Map<Character, Integer> freq) {
    PriorityQueue<HNode> pq = new PriorityQueue<>();
    freq.forEach((c, f) -> pq.offer(new HNode(c, f)));
    while (pq.size() > 1) pq.offer(new HNode(pq.poll(), pq.poll()));      // merge the two smallest
    Map<Character, String> codes = new HashMap<>();
    build(pq.peek(), "", codes);
    return codes;                                                          // O(n log n)
}
static void build(HNode n, String code, Map<Character, String> codes) {
    if (n == null) return;
    if (n.left == null && n.right == null) { codes.put(n.ch, code.isEmpty() ? "0" : code); return; }
    build(n.left, code + "0", codes);
    build(n.right, code + "1", codes);
}

Used in ZIP/GZIP (DEFLATE), JPEG and MP3 compression.

07Greedy Strategy Checklist

  1. Can I sort the input by some key (end time, ratio, deadline, frequency)?
  2. Is there a natural "best next" choice (smallest, largest, earliest, cheapest)?
  3. Does making that choice leave a smaller problem of the same type?
  4. Try to break it with a counter-example; try to prove it with an exchange argument

Typical sort keys

08Common Mistakes

  • Assuming greedy works without testing small counter-examples (coin change with arbitrary denominations, 0/1 knapsack)
  • Sorting by the wrong key (start instead of end for non-overlapping intervals)
  • Overflow when comparing with subtraction in comparators
  • Forgetting tie-breaking rules (equal end times, equal ratios)
  • Off-by-one on interval touching (start >= lastEnd vs >)

09Quick Recap

  • Greedy = best local choice, never revisited; needs the greedy-choice property and optimal substructure
  • Prove with an exchange argument; refute with a small counter-example
  • Works: intervals (earliest finish), fractional knapsack, jump game, gas station, Huffman, Dijkstra, Kruskal/Prim
  • Fails: arbitrary coin change, 0/1 knapsack → use dynamic programming
  • Typical shape: sort (or heap) + one pass, O(n log n)
