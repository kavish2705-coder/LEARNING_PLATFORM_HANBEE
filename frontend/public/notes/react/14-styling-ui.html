Styling, UI Libraries and Animation

Style React apps with plain CSS, CSS Modules, Tailwind CSS and component libraries like shadcn/ui, then add motion with CSS and the Motion library. Includes dark mode and responsive design.

02Plain CSS

import "./Card.css";

function Card({ active, children }) {
  return <div className={`card ${active ? "card--active" : ""}`}>{children}</div>;
}

Use a naming convention like BEM (card__title--large) to avoid clashes.

Conditional class names with clsx

npm install clsx
import clsx from "clsx";
<button className={clsx("btn", variant === "primary" && "btn--primary", { "btn--disabled": disabled })} />

03CSS Modules

File name ends with .module.css. Class names are locally scoped.

.card { padding: 1rem; border-radius: 12px; background: var(--surface); }
.title { font-size: 1.25rem; }
.active { outline: 2px solid var(--accent); }
import styles from "./Card.module.css";
import clsx from "clsx";

<div className={clsx(styles.card, isActive && styles.active)}>
  <h3 className={styles.title}>{title}</h3>
</div>

04Modern CSS You Should Use

:root {
  --bg: oklch(0.98 0.01 90);
  --ink: oklch(0.22 0.02 60);
  --accent: oklch(0.6 0.18 250);
  --radius: 12px;
}
@media (prefers-color-scheme: dark) { :root { --bg: oklch(0.2 0.01 60); --ink: oklch(0.95 0.01 90); } }

.grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr)); gap: 1rem; }
.card { container-type: inline-size; }                             /* container queries */
@container (min-width: 30rem) { .card__body { display: flex; } }
.title { font-size: clamp(1.5rem, 2vw + 1rem, 3rem); text-wrap: balance; }   /* fluid type */
button:has(+ .error) { outline-color: red; }                       /* :has() parent selector */
.btn { transition: transform 0.2s cubic-bezier(0.16, 1, 0.3, 1); }
@media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }
  • CSS variables make theming simple
  • Flexbox for 1-D layout, Grid for 2-D layout
  • Mobile-first: write base styles for small screens, add min-width media queries

05Tailwind CSS

A utility-first framework: compose designs with small classes directly in JSX. Unused classes are removed at build time, so output CSS is tiny.

npm install tailwindcss @tailwindcss/vite
import tailwindcss from "@tailwindcss/vite";
export default defineConfig({ plugins: [react(), tailwindcss()] });
@import "tailwindcss";

@theme {
  --color-brand: oklch(0.6 0.18 250);
  --font-display: "Fraunces", serif;
}
function CourseCard({ course }) {
  return (
    <article className="rounded-2xl border border-neutral-200 bg-white p-5 shadow-sm transition hover:-translate-y-0.5 hover:shadow-md dark:border-neutral-800 dark:bg-neutral-900">
      <h3 className="text-lg font-semibold tracking-tight">{course.title}</h3>
      <p className="mt-1 line-clamp-2 text-sm text-neutral-600 dark:text-neutral-400">{course.summary}</p>
      <button className="mt-4 rounded-lg bg-brand px-4 py-2 text-sm font-medium text-white hover:opacity-90 focus-visible:outline-2 focus-visible:outline-offset-2 disabled:opacity-50">
        Enroll
      </button>
    </article>
  );
}

Variants with class-variance-authority + tailwind-merge

import { cva } from "class-variance-authority";
import { twMerge } from "tailwind-merge";

const button = cva("inline-flex items-center rounded-lg font-medium transition", {
  variants: {
    variant: { primary: "bg-brand text-white", ghost: "bg-transparent hover:bg-neutral-100" },
    size: { sm: "px-3 py-1.5 text-sm", md: "px-4 py-2" },
  },
  defaultVariants: { variant: "primary", size: "md" },
});

function Button({ variant, size, className, ...props }) {
  return <button className={twMerge(button({ variant, size }), className)} {...props} />;
}

06CSS-in-JS (styled-components / Emotion)

const Button = styled.button`
  padding: 0.5rem 1rem;
  background: ${p => (p.$primary ? "navy" : "white")};
`;

Works, but runtime styling adds cost and is awkward with React Server Components. For new projects prefer CSS Modules, Tailwind or a zero-runtime solution.

Tip

Don't build modals, dropdowns, comboboxes and tooltips from scratch. They have difficult accessibility requirements (focus trapping, keyboard navigation, ARIA). Use headless libraries.

08Dark Mode

function useTheme() {
  const [theme, setTheme] = useState(() =>
    localStorage.getItem("theme") ?? (matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light")
  );
  useEffect(() => {
    document.documentElement.dataset.theme = theme;       // CSS: :root[data-theme="dark"] { ... }
    localStorage.setItem("theme", theme);
  }, [theme]);
  return [theme, setTheme];
}

Set the theme before first paint (small inline script in index.html) to avoid a flash of the wrong theme. In Tailwind v4 define the dark variant with @custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *));.

09Responsive Design

  • Mobile-first CSS with min-width breakpoints
  • Use rem, clamp() and %/fr units rather than fixed pixels
  • Test touch targets (about 44px), thumb reach and landscape
  • <meta name="viewport" content="width=device-width, initial-scale=1"> is required
  • Images: width/height attributes, loading="lazy", srcset/sizes, modern formats

11Animation

CSS transitions and keyframes (preferred for simple effects)

.card { transition: transform .25s ease, box-shadow .25s ease; }
.card:hover { transform: translateY(-3px); }

@keyframes fade-in { from { opacity: 0; transform: translateY(8px); } to { opacity: 1; transform: none; } }
.enter { animation: fade-in .4s cubic-bezier(0.16, 1, 0.3, 1) both; }

Animate transform and opacity (GPU-friendly); avoid animating width, height, top, left.

Motion (formerly Framer Motion)

npm install motion
import { motion, AnimatePresence } from "motion/react";

<motion.div
  initial={{ opacity: 0, y: 16 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.4, ease: [0.16, 1, 0.3, 1] }}
  whileHover={{ scale: 1.03 }}
/>

<AnimatePresence>
  {open && <motion.div key="panel" initial={{ height: 0 }} animate={{ height: "auto" }} exit={{ height: 0 }} />}
</AnimatePresence>

<motion.li layout />                         {/* animates reordering automatically */}

Animation guidelines

  • Motion should answer what changed, what matters, where to look
  • Keep durations 150 to 400 ms; use easing like cubic-bezier(0.16, 1, 0.3, 1)
  • Respect prefers-reduced-motion (Motion: useReducedMotion())
  • Don't animate on every scroll event; use CSS scroll-driven animations or IntersectionObserver
  • View Transitions API (document.startViewTransition) gives native page/state transitions

12Accessibility in Styling

  • Colour contrast ratio at least 4.5:1 for body text, 3:1 for large text/UI parts
  • Visible focus styles (:focus-visible), never outline: none without a replacement
  • Don't convey meaning by colour alone
  • Support zoom to 200% and text resizing
  • Check with Lighthouse, axe DevTools and keyboard-only navigation

13Quick Recap

  • Pick one primary approach: CSS Modules or Tailwind for most projects
  • Use CSS variables, Grid/Flexbox, clamp() and container queries
  • Use headless libraries (Radix, React Aria) or shadcn/ui for accessible components
  • Animate transform/opacity; use Motion for complex sequences; honour reduced motion
  • Design mobile-first, keep contrast and focus styles accessible
