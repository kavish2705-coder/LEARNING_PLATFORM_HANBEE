React 19 New Features

A guided tour of what React 19 adds. Actions, useActionState, useFormStatus, useOptimistic, the use API, ref as a prop, metadata and resource support, better error handling, and the 19.1/19.2 additions.

02Actions

An Action is an async function used in a transition. React tracks its pending state, handles errors, supports optimistic updates and resets forms for you.

function UpdateName() {
  const [name, setName] = useState("");
  const [error, setError] = useState(null);
  const [isPending, startTransition] = useTransition();

  const handleSubmit = () => {
    startTransition(async () => {                 // async function inside a transition = Action
      const err = await updateName(name);
      if (err) { setError(err); return; }
      redirect("/profile");
    });
  };

  return (
    <div>
      <input value={name} onChange={e => setName(e.target.value)} />
      <button onClick={handleSubmit} disabled={isPending}>Update</button>
      {error && <p>{error}</p>}
    </div>
  );
}

Before React 19 you wrote isPending, error and try/catch/finally state manually for every mutation.

Form Actions: <form action={fn}>

async function enroll(formData) {                 // receives FormData
  const email = formData.get("email");
  await api.enroll(email);
}

<form action={enroll}>
  <input name="email" type="email" required />
  <button>Enroll</button>
</form>
  • When action is a function, React calls it with the form's FormData on submit (no preventDefault, no controlled inputs needed)
  • After a successful action, uncontrolled fields reset automatically
  • Works with progressive enhancement when used with Server Functions
  • Buttons can override with formAction={otherFn}

03useActionState

Wraps an action and gives you its latest result and pending flag. (Replaces the older useFormState from react-dom.)

import { useActionState } from "react";

async function signup(prevState, formData) {      // (previous state, form data)
  const email = formData.get("email");
  if (!email.includes("@")) return { error: "Enter a valid email" };
  await api.signup(email);
  return { success: true };
}

function Signup() {
  const [state, formAction, isPending] = useActionState(signup, { error: null });

  return (
    <form action={formAction}>
      <input name="email" type="email" />
      <button disabled={isPending}>{isPending ? "Joining…" : "Join"}</button>
      {state.error && <p role="alert">{state.error}</p>}
      {state.success && <p>Welcome aboard!</p>}
    </form>
  );
}

Signature: const [state, action, isPending] = useActionState(fn, initialState, permalink?)

04useFormStatus

Reads the status of the parent <form> from any child component, which is perfect for reusable submit buttons. Imported from react-dom.

import { useFormStatus } from "react-dom";

function SubmitButton({ children }) {
  const { pending, data, method, action } = useFormStatus();
  return <button type="submit" disabled={pending}>{pending ? "Saving…" : children}</button>;
}

<form action={save}>
  <input name="title" />
  <SubmitButton>Save</SubmitButton>          {/* must be rendered INSIDE the form */}
</form>
Warning

useFormStatus only reports on a <form> that is an ancestor of the component calling it, not a form rendered by the same component.

05useOptimistic

Show the expected result immediately while the real request is in flight. If the action fails, React automatically reverts to the real state.

import { useOptimistic } from "react";

function Messages({ messages, sendMessage }) {
  const [optimisticMessages, addOptimistic] = useOptimistic(
    messages,
    (current, newText) => [...current, { id: "temp", text: newText, sending: true }]
  );

  async function formAction(formData) {
    const text = formData.get("text");
    addOptimistic(text);                      // appears instantly
    await sendMessage(text);                  // real update; state is replaced when `messages` changes
  }

  return (
    <>
      {optimisticMessages.map(m => (
        <p key={m.id} style={{ opacity: m.sending ? 0.5 : 1 }}>{m.text}</p>
      ))}
      <form action={formAction}><input name="text" /><button>Send</button></form>
    </>
  );
}

Great for likes, comments, todo toggles and any UI where waiting for the server feels slow.

06The use API

use reads a resource: a Promise or a Context. Unlike hooks, it can be called conditionally and inside loops.

Reading a promise (with Suspense)

import { use, Suspense } from "react";

function Comments({ commentsPromise }) {
  const comments = use(commentsPromise);          // suspends until resolved; throws if rejected
  return comments.map(c => <p key={c.id}>{c.text}</p>);
}

function Page({ id }) {
  const commentsPromise = fetchComments(id);      // created in a parent / Server Component
  return (
    <ErrorBoundary fallback={<p>Failed to load</p>}>
      <Suspense fallback={<p>Loading comments…</p>}>
        <Comments commentsPromise={commentsPromise} />
      </Suspense>
    </ErrorBoundary>
  );
}
Warning

Don't create the promise inside the component that calls use during render in a Client Component: a new promise each render causes an endless suspend loop. Create it in a parent, a Server Component, a cache, or a data library.

Reading context conditionally

function Button({ show }) {
  if (!show) return null;
  const theme = use(ThemeContext);               // allowed after an early return
  return <button className={theme}>OK</button>;
}

07ref as a Prop and Ref Cleanup

function MyInput({ ref, ...props }) { return <input ref={ref} {...props} />; }   // no forwardRef

<input ref={(node) => { /* setup */ return () => { /* cleanup */ }; }} />        // cleanup functions

Details are in the Refs topic. Note: ref callbacks should no longer use implicit return of an assignment (ref={el => (instance = el)}); use braces.

09Document Metadata

Render <title>, <meta> and <link> anywhere; React hoists them into <head> (works with client rendering, streaming SSR and Server Components).

function BlogPost({ post }) {
  return (
    <article>
      <h1>{post.title}</h1>
      <title>{post.title}</title>
      <meta name="author" content={post.author} />
      <meta name="keywords" content={post.keywords} />
      <link rel="canonical" href={`https://hanbee.com/blog/${post.slug}`} />
    </article>
  );
}

Libraries like React Helmet are usually unnecessary now.

10Stylesheets and Scripts

function Widget() {
  return (
    <Suspense fallback="loading…">
      <link rel="stylesheet" href="/widget.css" precedence="default" />   {/* ordered, deduped, awaited */}
      <div className="widget">…</div>
    </Suspense>
  );
}

<script async src="https://example.com/analytics.js" />                 {/* deduped across components */}
  • precedence tells React how to order stylesheets and lets it wait for the CSS before revealing content (no flash of unstyled content)
  • Async scripts rendered in many components load once

12Better Error Reporting

const root = createRoot(container, {
  onCaughtError: (error, info) => reportToSentry(error, info.componentStack),      // caught by an Error Boundary
  onUncaughtError: (error, info) => reportToSentry(error, info.componentStack),    // not caught
  onRecoverableError: (error, info) => console.warn(error),                        // React recovered
});
  • Errors are no longer logged twice
  • Hydration mismatch errors now show a clear diff instead of several vague messages
  • Third-party scripts or browser extensions that inject tags into <head>/<body> no longer break hydration

Know when a cache() result is no longer needed so you can abort in-flight work.

18Putting It Together: A Form with All the New Pieces

import { useActionState, useOptimistic } from "react";
import { useFormStatus } from "react-dom";

function Submit() {
  const { pending } = useFormStatus();
  return <button disabled={pending}>{pending ? "Posting…" : "Post"}</button>;
}

export default function Comments({ initial, postComment }) {
  const [comments, setComments] = useState(initial);
  const [optimistic, addOptimistic] = useOptimistic(comments, (cur, text) => [...cur, { id: "tmp", text, pending: true }]);

  const [state, action] = useActionState(async (_prev, formData) => {
    const text = formData.get("text");
    if (text.length < 3) return { error: "Too short" };
    addOptimistic(text);
    const saved = await postComment(text);
    setComments(c => [...c, saved]);
    return { error: null };
  }, { error: null });

  return (
    <>
      <ul>{optimistic.map(c => <li key={c.id} style={{ opacity: c.pending ? 0.5 : 1 }}>{c.text}</li>)}</ul>
      <form action={action}>
        <input name="text" />
        <Submit />
        {state.error && <p role="alert">{state.error}</p>}
      </form>
    </>
  );
}

19Quick Recap

  • Actions = async functions in transitions with built-in pending, error and form reset handling
  • useActionState, useFormStatus, useOptimistic and <form action={fn}> replace most hand-written form plumbing
  • use(promise | context) can be called conditionally; promises must be created outside render
  • ref is a prop, ref callbacks may clean up, <Context value> replaces .Provider
  • <title>, <meta>, <link> and stylesheets work from any component
  • 19.2 adds <Activity>, useEffectEvent, Performance Tracks; the Compiler 1.0 automates memoisation
  • Check removals (propTypes, defaultProps, ReactDOM.render) before upgrading
